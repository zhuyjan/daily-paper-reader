## 摘要
训练工具使用型代理从其自身经验中改进仍然具有挑战性，因为监督微调依赖于固定的教师蒸馏轨迹，而稀疏奖励强化学习为长程交互提供的监督较弱。我们提出DeepSearch-Evolve，这是一个基于DeepSearch-World构建的Web代理自蒸馏框架，DeepSearch-World是一个确定且可验证的环境，配备了可复现的搜索和页面阅读工具。DeepSearch-World包含42万个从实体级随机游走构建的多跳问答任务，并支持对自我进化有用的关键代理认知行为，包括进度验证、基于推理的反思和失败恢复。DeepSearch-Evolve迭代执行轨迹生成、过滤、数据混合和微调，以训练更强的代理。在没有从更强模型蒸馏的情况下，DeepSearch-World-9B在与开源代理的比较中取得了有竞争力的性能，在BrowseComp上达到31.2%，在GAIA上达到61.5%，在HotpotQA上达到93.4%，这表明可验证环境使得长程Web代理能够进行可扩展的自我进化。我们将发布环境、42万训练池、验证集、模型和代码，以促进未来关于自我改进深度搜索代理的研究。

## Abstract
Training tool-use agents to improve from their own experience remains challenging, as supervised fine-tuning relies on fixed teacher-distilled trajectories, while sparse-reward reinforcement learning provides weak supervision for long-horizon interactions. We present DeepSearch-Evolve, a self-distillation framework for web agents built on DeepSearch-World, a deterministic and verifiable environment with reproducible search and page-reading tools. DeepSearch-World contains 420K multi-hop QA tasks constructed from entity-level random walks and supports key agentic cognitive behaviors useful for self-evolving, including progress verification, grounded reflection, and failure recovery. DeepSearch-Evolve iteratively performs trajectory generation, filtering, data mixing, and fine-tuning to train stronger agents. Without distillation from more capable models, DeepSearch-World-9B achieves competitive performance compared with open-source agents, reaching 31.2% on BrowseComp, 61.5% on GAIA, and 93.4% on HotpotQA, showing that verifiable environments enable scalable self-evolution for long-horizon web agents. We will release the environment, 420K training pool, validation set, model, and code to facilitate future research on self-improving deep search agents.

- **研究动机**：大型语言模型工具使用代理（如Web代理）在执行多步任务时，需要从自身交互经验中自主改进，但现有方法面临两大挑战：

## 2. 方法论
- **核心思想**：提出DeepSearch-Evolve自蒸馏框架，构建于DeepSearch-World可验证环境之上。通过迭代进行轨迹生成、拒绝采样与质量过滤、Scaffold-to-ReAct转换、监督微调，使代理从自身的已验证工具使用经验中学习规划、记忆、自我修正等高级认知行为。
- **关键技术细节**：
  - **DeepSearch-World环境**：
    - 基于Wikipedia知识图谱构建42万实体级多跳QA任务，每个任务需恢复目标实体链。
    - 提供两种确定性工具：`web_search_wiki`（BM25检索返回标题、摘要、URL）和`visit_wiki`（SQLite索引返回完整文章）。
    - 支持环境级进度验证：存储真值实体集，工具调用成功则匹配并移除实体；失败时触发阶段式规则反思。
  - **Scaffold教师代理**：
    - 三阶段生成：Plan（初始化结构化进度状态，包含completed_list, todo_list, experience, information）、Act（最多Tmax=30步，通过公式\( s_{t+1} = U(s_t, a_t, o_t, r_t) \)更新状态）、End（生成基于已验证工作记忆的简洁答案）。
  - **自进化训练循环**：
    - 每轮生成10K问题轨迹，收集至少4K正确轨迹后再训练。
    - 使用Qwen3.5-9B进行轨迹质量过滤（去除冗余证据、弱目标对齐、推理不一致）。
    - Scaffold-to-ReAct转换：移除阶段专用提示，将进度状态和反思重写为`<think>`块中的推理轨迹：`<think>_t = P_t ⊕ R_t ⊕ A_t`。
    - 损失函数为标准SFT：\( L_{\text{SFT}}(\theta) = \mathbb{E}_{\tilde{\tau} \sim \tilde{D}(R)} \sum_{t=1}^{T} \text{KL}(\delta_{y_t} \| \pi_\theta(\cdot | x, y_{<t})) \)。
    - 采用重要性采样混合各轮数据，衰减因子γ=0.5，优先使用新数据同时保留旧轨迹以防灾难性遗忘。
- **流程**：11轮自我进化循环（异步生成与训练），使用Llama Factory进行单轮微调，学习率5e-6，最大序列长度32768。

## 6. 主要结论与发现
- DeepSearch-World-9B在无更强模型蒸馏的情况下，在BrowseComp（31.2%）、GAIA（61.5%）、HotpotQA（93.4%）等基准上取得了与开源代理有竞争力的性能，大幅超越骨干模型Qwen3.5-9B-Instruct（+23.8/+37.6/+48.1）。
- 较大数据池（420K vs 100K）能支撑更多轮进化，获得更高的验证得分、更低格式错误率及更稳定的工具成功率和实体命中率，说明**数据多样性是自我进化的关键**。
- 轨迹质量过滤（RS+QF）显著优于仅使用答案正确性过滤（RS）或仅质量过滤（QF），以及现有OPSD和Skill-SD方法。
- 环境级进度验证和反思信号有效：移除状态内化或反思重写后性能大幅下降（从31.9降至23.5/16.7）。
- 可验证环境使得代理能够从自身经验中迭代学习规划、记忆、自我修正等高级行为，而无需依赖更强的教师模型。

## 7. 优点
