## 摘要
计算机使用智能体（CUA）正成为一种通过视觉感知和图形用户界面执行来自动化复杂数字工作流的强大接口。基于可验证奖励的在线强化学习（RLVR）已成为扩展其能力的关键方向。然而，该范式受限于可验证数据稀缺和在线强化学习效率低下。为突破这些瓶颈，我们提出ScaleCUA，一个通过可验证任务合成和高效训练来扩展CUA在线强化学习的统一框架。在数据层面，我们设计了VeriGen，一个端到端框架，通过迭代的Docker交互和多智能体反馈循环生成可验证的强化学习任务。通过共享的Docker交互探针扩展到100多个并发智能体工作进程，该流水线产生超过24K个可验证任务和近3K个高质量强化学习任务。为最大化样本效率，我们提出前沿采样（Frontier Sampling），该方法跟踪每个任务的能力并将探索分配到当前学习前沿。在训练方面，我们进一步设计了视觉上下文分割（Visual Context Segmentation），即对最近视觉上下文进行滑动窗口处理，以平衡探索和训练引擎压力，相较于逐步分解实现了2.83倍的训练加速。综合来看，ScaleCUA在OSWorld上达到68.7%，在ScienceBoard上达到54.0%，在开源计算机使用智能体中树立了新的最先进性能。代码、模型和数据集见https://github.com/THUDM/SCALE-CUA。

## Abstract
Computer use agents (CUAs) are emerging as a powerful interface for automating complex digital workflows through visual perception and GUI execution. Online reinforcement learning with verifiable rewards (RLVR) has emerged as a key direction for scaling their capabilities. However, this paradigm is bottlenecked by verifiable data scarcity and online RL inefficiency. To break these barriers, we introduce ScaleCUA, a unified framework that scales online RL for CUAs via verifiable task synthesis and efficient training. At the data level, we design VeriGen, an end-to-end framework for generating verifiable RL tasks through iterative docker interactions and a multi-agent feedback loop. Scaled to 100+ concurrent agent workers via a shared docker interaction probe, this pipeline produces 24K+ verifiable tasks and nearly 3K high-quality RL tasks. To maximize sample efficiency, we propose Frontier Sampling, which tracks per-task capability and allocates rollouts to the current learning frontier. On the training side, we further design Visual Context Segmentation, a sliding window over recent visual context that balances rollout and training-engine pressure, yielding a 2.83x training speedup over step-wise decomposition. Together, ScaleCUA achieves 68.7% on OSWorld and 54.0% on ScienceBoard, establishing new state-of-the-art performance among open-source computer use agents. Code, models, and datasets are available at https://github.com/THUDM/SCALE-CUA.

- **核心含义**：本文提出 **SCALECUA**，一个统一框架，通过**可验证任务合成**（VeriGen）和**高效在线 RL**（Frontier Sampling + Visual Context Segmentation）来系统性地解决上述瓶颈，从而扩展 CUA 的在线 RL 规模并提升性能。

## 2. 方法论

### 核心思想
- **VeriGen**：端到端生成可验证 GUI 任务的流水线。利用多智能体反馈循环与实时 Docker 环境交互，自动合成任务指令和确定性判分函数，并通过轨迹引导合成（trajectory-guided synthesis）进一步产生难度合适的 RL 任务。
- **Frontier Sampling**：基于每个任务的成功率指数移动平均（EMA），动态分配探索（rollout）到模型当前“学习前沿”的任务，避免在已掌握或过于困难的任务上浪费资源。
- **Visual Context Segmentation**：滑动窗口策略，保留最近 K 帧视觉上下文（截图），文本历史保持连续，将长轨迹切分为多个训练段，平衡推理引擎与训练引擎压力，实现 2.83× 端到端训练加速。

### 关键技术细节
- **VeriGen 多智能体循环**：
  - 三个 LLM 智能体：`proposer`（生成任务+验证器）、`judger`（静态语义审查）、`checker`（在 Docker 中动态执行验证）。
  - 通过共享 Docker 探针（probe）支持 100+ 并发工作进程，产生 **24K+ 可验证任务**，最终筛选出约 3K 高质量 RL 任务。
  - 轨迹引导合成：对失败任务切分为更易的子任务，对成功任务组合为更难的多目标任务。
- **Frontier Sampling 公式**：
  - 每轮更新任务 i 的 EMA 成功率：\( \hat{p}_i \leftarrow (1-\alpha)\hat{p}_i + \alpha \cdot \frac{1}{n}\sum_{j=1}^n \mathbb{1}[\text{rollout}_j \text{ succeeds}] \)
  - 采样权重：\( w_i = \exp\left(-\frac{(\hat{p}_i-\mu)^2}{2\sigma^2}\right) \)，其中 \(\mu=0.5,\sigma=0.25\)，并保留 20% 的均匀采样用于探索。
- **Visual Context Segmentation 算法**：
  - 用 token-ID 流保存逐步 token 差异，维持 loss mask 对齐。
  - 当截图数超过 \(K+\Delta\) 时触发裁剪：保存当前段，丢弃最旧的 \(\Delta\) 张截图，重 token 化剩余历史。
  - 默认 \(K=\Delta=5\)（OSWorld）或 8（ScienceBoard），使得训练段数量从 step-wise 的 \(O(nT)\) 降低到 \(O(nT/K)\)。
- **RL 目标**：基于 GRPO + DAPO 非对称裁剪 + KL 惩罚。

## 6. 主要结论与发现

- **SCALECUA-Qwen3.5-9B** 在 OSWorld 上达到 **68.7%**，超越所有开源模型（包括 4 倍规模模型）和大多数闭源模型（如 Claude Sonnet 4.5 62.9%）。
- 在 ScienceBoard 上达到 **54.0%**，超越 Claude Opus 4.6（52.7%），尤其是在 TeXstudio（86.7%）和 Lean（19.0%）等专业任务上大幅领先。
- **VeriGen** 能够大规模生成可验证任务（24K+），且通过轨迹引导可进一步提升 RL 训练效果（从 64.6% 提升到 68.7%）。
- **Frontier Sampling** 持续保持更高的奖励曲线，优于均匀采样、DAPO、课程学习。
- **Visual Context Segmentation** 实现 **2.83× 训练加速**而不牺牲性能；最优窗口大小 K=5。
- 三个核心组件均贡献显著，去除任一组件（VeriGen、Frontier Sampling、Visual Context Segmentation）分数下降 >4%。

## 7. 优点

- **系统性解决数据瓶颈**：VeriGen 通过多智能体循环和 Docker 交互，自动生成可验证任务，第一次在 CUA 领域实现万级规模的可验证任务池，且质量经过人工审计（82.5% 一致）。
- **训练效率创新**：Frontier Sampling 基于 EMA 动态调整任务权重，避免无效探索；Visual Context Segmentation 通过滑动窗口大幅缩短训练时间，且不损失跨步推理能力。
- **模型无关性**：在 GLM-4.6V、Qwen3-VL、Qwen3.5 三种基座上均取得一致提升，证明框架通用性强。
- **全面细致的实验**：包含主结果、消融、效率、数据质量、人工审计、重叠检查，论证充分。
- **开源贡献**：代码、模型、数据集均公开，可复现。

## 8. 不足与局限

- **任务长度限制**：每个 episode 最多 50 步，可能无法覆盖超长工作流（如安装复杂软件）。
- **环境单一**：仅在 Ubuntu 桌面评估，未扩展到 Windows/macOS。
- **模型规模局限**：仅验证 8B–9B 类模型，更大（如 70B+）或更小规模的泛化性未知。

- **科学与工程复杂度**：需要大量 Docker 环境和多节点 GPU 集群，对小团队复制可能较困难。
- **未探索离线 RL 或纯行为克隆**：方法完全依赖在线 RL，是否需要大量在线交互仍有待研究。
