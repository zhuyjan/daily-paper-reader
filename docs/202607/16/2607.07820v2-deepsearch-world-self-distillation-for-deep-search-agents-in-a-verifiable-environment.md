## 摘要
训练工具使用代理从自身经验中改进仍然具有挑战性，因为监督微调依赖于固定的教师蒸馏轨迹，而稀疏奖励强化学习为长程交互提供的监督较弱。我们提出了DeepSearch-Evolve，这是一个基于DeepSearch-World构建的web代理自蒸馏框架，DeepSearch-World是一个确定性和可验证的环境，具有可复现的搜索和页面阅读工具。DeepSearch-World包含从实体级随机游走构建的42万条多跳问答任务，并支持对自演化有用的关键代理认知行为，包括进度验证、基于事实的反思和失败恢复。DeepSearch-Evolve迭代地进行轨迹生成、过滤、数据混合和微调，以训练更强的代理。在没有更强大模型蒸馏的情况下，DeepSearch-World-9B在BrowseComp上达到31.2%，在GAIA上达到61.5%，在HotpotQA上达到93.4%，与开源代理相比具有竞争力，这表明可验证环境能够实现长程web代理的可扩展自演化。我们将发布环境、42万训练池、验证集、模型和代码，以促进未来对自我改进的深度搜索代理的研究。

## Abstract
Training tool-use agents to improve from their own experience remains challenging, as supervised fine-tuning relies on fixed teacher-distilled trajectories, while sparse-reward reinforcement learning provides weak supervision for long-horizon interactions. We present DeepSearch-Evolve, a self-distillation framework for web agents built on DeepSearch-World, a deterministic and verifiable environment with reproducible search and page-reading tools. DeepSearch-World contains 420K multi-hop QA tasks constructed from entity-level random walks and supports key agentic cognitive behaviors useful for self-evolving, including progress verification, grounded reflection, and failure recovery. DeepSearch-Evolve iteratively performs trajectory generation, filtering, data mixing, and fine-tuning to train stronger agents. Without distillation from more capable models, DeepSearch-World-9B achieves competitive performance compared with open-source agents, reaching 31.2% on BrowseComp, 61.5% on GAIA, and 93.4% on HotpotQA, showing that verifiable environments enable scalable self-evolution for long-horizon web agents. We will release the environment, 420K training pool, validation set, model, and code to facilitate future research on self-improving deep search agents.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **动机**：训练工具使用的 LLM 代理（web agent）从自身交互经验中自主改进是当前的一大挑战。
- **现有方法局限**：
  - **监督微调（SFT）**：依赖固定教师蒸馏轨迹，性能容易饱和，受限于 backbone 能力和轨迹多样性。
  - **强化学习（RL）**：奖励稀疏（仅最终结果），缺乏对中间工具调用步骤的指导。
  - **在线策略自蒸馏（OPSD）**：虽可提供密集 token 级监督，但在长程 tool-use 中，教师分布可能因环境和动作噪声而不稳定。
- **本文目标**：构建一个**确定性、可验证的环境**（DeepSearch-World），结合**自蒸馏框架**（DeepSearch-Evolve），使代理能够从自身已验证的工具使用经验中迭代改进，无需更强模型蒸馏。

## 2. 论文提出的方法论

### 2.1 核心思想
- 设计一个完全离线的、基于 Wikipedia 的确定性环境（DeepSearch-World），提供可复现的搜索和阅读工具，并支持实体级别的过程验证（progress verification）和基于事实的反思（grounded reflection）。
- 利用该环境，通过自蒸馏循环：教师代理生成带脚手架（scaffold）的轨迹 → 过滤正确答案 → 转换为标准 ReAct 格式 → 学生代理通过 SFT 学习 → 学生成为下一轮教师。

### 2.2 关键技术细节

#### a) DeepSearch-World 环境
- **数据构建**：基于 Wikipedia 超链接图进行实体级随机游走，生成 42 万个多跳 QA 任务。每个问题对应隐藏的目标实体集合 $\mathcal{T}_i$。
- **工具**：`web_search_wiki`（基于 Pyserini BM25 索引，返回标题、摘要、URL）和 `visit_wiki`（通过 SQLite 偏移索引获取全文）。
- **过程验证**：环境维护已完成实体集合 $S_t \subseteq \mathcal{T}_i$，每次工具调用后自动判断是否匹配未完成实体，更新进度。失败时触发分阶段规则反射（首次泛化、后续更强指导）。

#### b) 脚手架教师代理（Scaffold Teacher）
- 三阶段：
  - **Plan**：初始化进度状态 $s_0$（completed_list, todo_list, experience, information）。
  - **Act**：循环执行 $t=1$ 到 $T_{\max}$，选择工具调用 $a_t$，接收观察 $o_t$ 和环境反射 $r_t$，更新状态 $s_{t+1} = U(s_t, a_t, o_t, r_t)$。
  - **End**：证据充足或预算耗尽时生成简洁答案，避免幻觉。
- 仅用于轨迹生成，不暴露给学生。

#### c) 自蒸馏训练循环
- 每轮 $R$：当前模型 $\pi_{\theta_R}$ 作为教师生成轨迹，经答案正确性筛选和轨迹质量过滤（使用 Qwen3.5-9B 作为评判器）。
- **Scaffold → ReAct 转换**：将进度状态和反射写入 `<think>` 块：`<think>_t = P_t ⊕ R_t ⊕ A_t`，动作和观察保持原样。
- **SFT 更新**：最小化负对数似然：$\mathcal{L}_{\text{SFT}}(\theta) = \mathbb{E}_{\tilde{\tau} \sim \tilde{\mathcal{D}}^{(R)}} \sum_{t=1}^T \text{KL}(\delta_{y_t} \| \pi_\theta(\cdot | x, y_{<t}))$。
- 采用重要性采样混合多轮数据，衰减因子 $\gamma=0.5$，优先最新已验证数据。

## 6. 论文的主要结论与发现

- 在没有更强模型蒸馏的情况下，DeepSearch-World-9B 在其 backbone（Qwen3.5-9B-Instruct）基础上获得显著提升：BrowseComp +23.8 个百分点，GAIA +37.6，HotpotQA +48.1。
- 在与开源代理对比中，DeepSearch-World-9B 达到领先或相当水平（例如 BrowseComp 31.2%，GAIA 61.5%）。
- **过程验证+自蒸馏**的有效性：验证轨迹过滤是关键，质量过滤进一步增益；状态内化和反射重写均有助于性能提升。
- **数据多样性**至关重要：420K 池比 100K 池更晚饱和，持续提供新任务和失败恢复模式，避免了过拟合到窄交互模式。
- **行为变化**：训练后的代理维持更长交互（平均 18.0 轮 vs. 4.7 轮）、更多工具调用（搜索 12.6 次 vs. 3.8 次，访问 5.4 次 vs. 0.9 次），高级能力评分从 19% 升至 70%。

## 8. 不足与局限

- **环境局限**：目前仅基于 Wikipedia，覆盖世界知识和领域多样性有限。扩展到更广知识源（如新闻、文档、实时网页）可能面临挑战，但工具接口设计已对齐真实 Web 工具，迁移潜力存在。
- **训练范式局限**：当前采用 SFT 自蒸馏，虽然稳定但可能不如 RL 或 OPSD 能够进一步提升泛化和灵活性。如何将高级认知能力（如规划、错误恢复）融入 RL 训练尚未解决。
- **反射重写依赖**：反射重写掩盖了实体名称以免答案泄露，但可能丢失某些有益的信号，或引入噪声（如原始反射中残留 `[REFLECTION]` 标记）。
- **跨语言/多模态**：实验仅限英文文本，中文 benchmark 虽测试但性能较低；未涉及多模态搜索（如图片、PDF），可能限制在真实复杂场景的应用。
- **安全性考虑**：虽然环境离线可控，但训练数据包含 Wikipedia 中可能存在的社会偏见，论文也承认模型可能继承此类偏见，需进一步安全对齐。
