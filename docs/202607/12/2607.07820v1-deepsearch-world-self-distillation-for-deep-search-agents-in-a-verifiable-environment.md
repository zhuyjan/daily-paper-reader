## 摘要
训练工具使用代理从自身经验中改进仍然具有挑战性，因为监督微调依赖于固定的教师蒸馏轨迹，而稀疏奖励强化学习为长程交互提供了弱监督。我们提出了DeepSearch-Evolve，一个构建在DeepSearch-World之上的自蒸馏框架，DeepSearch-World是一个确定且可验证的环境，具有可复现的搜索和页面阅读工具。DeepSearch-World包含42万个从实体级随机游走构建的多跳问答任务，并支持对自进化有用的关键代理认知行为，包括进度验证、基于基础的反思和失败恢复。DeepSearch-Evolve迭代执行轨迹生成、过滤、数据混合和微调，以训练更强的代理。在没有从更强模型进行蒸馏的情况下，DeepSearch-World-9B在开源代理中取得了具有竞争力的性能，在BrowseComp上达到31.2%，在GAIA上达到61.5%，在HotpotQA上达到93.4%，这表明可验证环境能够支持长程网络代理的可扩展自进化。我们将发布环境、42万训练池、验证集、模型和代码，以促进未来关于自改进深度搜索代理的研究。

## Abstract
Training tool-use agents to improve from their own experience remains challenging, as supervised fine-tuning relies on fixed teacher-distilled trajectories, while sparse-reward reinforcement learning provides weak supervision for long-horizon interactions. We present DeepSearch-Evolve, a self-distillation framework for web agents built on DeepSearch-World, a deterministic and verifiable environment with reproducible search and page-reading tools. DeepSearch-World contains 420K multi-hop QA tasks constructed from entity-level random walks and supports key agentic cognitive behaviors useful for self-evolving, including progress verification, grounded reflection, and failure recovery. DeepSearch-Evolve iteratively performs trajectory generation, filtering, data mixing, and fine-tuning to train stronger agents. Without distillation from more capable models, DeepSearch-World-9B achieves competitive performance compared with open-source agents, reaching 31.2% on BrowseComp, 61.5% on GAIA, and 93.4% on HotpotQA, showing that verifiable environments enable scalable self-evolution for long-horizon web agents. We will release the environment, 420K training pool, validation set, model, and code to facilitate future research on self-improving deep search agents.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题**：现有工具使用智能体（tool-use agents）缺乏从自身交互经验中持续改进的能力。监督微调（SFT）依赖固定教师蒸馏轨迹，受限于教师能力；稀疏奖励强化学习（如RL）对长程交互提供弱监督，难以定位失败来源（如查询构造、工具选择、证据提取等）。
- **背景**：在线策略自蒸馏（OPSD）可缓解奖励稀疏性，但需要确定性、可验证的交互环境以提供细粒度动作级监督；否则教师分布可能不可靠。
- **贡献**：提出**DeepSearch-World**（确定、可验证的离线环境）与**DeepSearch-Evolve**（自蒸馏框架），使开源模型无需强教师即可通过可验证的自经验提升搜索能力，在多个基准上达到竞争性能。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：  
  构建确定性Wikipedia离线环境，提供可复现的搜索/浏览工具和实体级进度验证；通过脚手架（scaffold）教师生成带规划、记忆、错误恢复的轨迹，再转换为标准的ReAct格式用于学生SFT训练，形成迭代自演进循环。

- **关键技术细节**：
  - **DeepSearch-World环境**：
    - 基于Wikipedia超链接图，采样实体级随机游走生成42万多跳QA任务，每个问题需通过搜索、浏览、推理恢复目标实体。
    - 工具：`web_search_wiki`（BM25检索返回标题+摘要+URL）和`visit_wiki`（SQLite偏移索引返回全文），确定性、可复现。
    - 环境内置实体级进度验证：维护已解决集合 \( S_t \subseteq T_i \)，当工具输出匹配未解决实体时更新 \( S_{t+1} \)，失败时触发分级规则反思（首次泛化提示，重复时提供规范名称或模糊描述）。
  - **脚手架教师代理**：
    - 三阶段：**Plan**（初始化结构化进度状态，含已完成列表、待办列表、经验、信息）、**Act**（迭代调用工具，状态更新 \( s_{t+1} = U(s_t, a_t, o_t, r_t) \)）、**End**（基于已验证工作记忆生成答案）。
    - 状态包含四个可写字段：`completed_list`、`todo_list`、`experience`、`information`。
  - **自演进训练循环**：
    - 第 \( R \) 轮使用当前模型 \( \pi_{\theta_R} \) 在环境中生成脚手架轨迹。
    - 保留答案正确的轨迹，并用人Qwen3.5-9B进行质量过滤（去除冗余、弱对齐、不一致）。
    - 将过滤后的脚手架轨迹转换为ReAct格式：将阶段提示去除，重写进度状态和反思为 <think> 块（如 \( Pt \oplus Rt \oplus At \)）。
    - 对转换后的轨迹进行SFT更新（硬标签令牌级策略蒸馏），损失为 \( L_{SFT}(\theta) = E_{\tilde{\tau} \sim \tilde{D}^{(R)}} \sum_t \text{KL}(\delta_{y_t} \| \pi_\theta(\cdot|x, y_{<t})) \)。
    - 异步生成与训练：每轮生成10k问题，积累4k通过过滤后触发训练；重要性采样跨轮混合，衰减因子γ=0.5。

## 6. 主要结论与发现

1. **可验证环境实现自进化**：DeepSearch-World-9B在BrowseComp（31.2%）、GAIA（61.5%）、HotpotQA（93.4%）上超越基线骨干（Qwen3.5-9B-Instruct）大幅提升（+23.8、+37.6、+48.1），并达到甚至超过部分依赖强教师蒸馏的开源代理。
2. **脚手架→ReAct转换有效**：重写反思（而非保留原始环境反馈）是性能关键（缺失时准确率从31.9%降至16.7%）；状态内化提供额外增益。
3. **拒绝采样+质量过滤协同作用**：仅RS带来主要提升（46.4→54.9），QF进一步提至58.2；超越OPSD和Skill-SD。
4. **大规模数据池防止饱和**：420K相比100K在11轮后仍未饱和，验证分数、工具成功率、实体命中率稳定提升，格式错误率更低。
5. **行为改进**：训练后智能体平均回合数从4.7提升至18.0，浏览调用从0.9增至5.4，高级能力评分从19%升至70%，表明学会了规划、记忆管理、错误恢复。
