## 摘要
检索系统的训练和评估基于静态的有用性概念：将文档和问题交给阅读器模型，观察答案是否改善，并据此对文档打分。当文档独立阅读时，这个想法成立。但当语言模型作为搜索智能体工作时，它会发出多个查询并在轮次间推理，这时该想法就不成立了，因为文档的重要性可能在于它让智能体下一步能做什么，而不是它对当前问题说了什么。我们测量这一差距，而非争论它。使用基于HotpotQA的ReAct风格智能体，我们重放1000个开发问题，并对智能体读取的每个文档进行删除，然后从该点重新运行轨迹的其余部分。将原始运行与其反事实运行进行比较，从三个差值中得出反事实轨迹效用分数：最终答案质量、下一查询检索质量和轮次数。将CTU与静态RAG效用（SRU）交叉比较，涵盖23,322个文档观测值，二者几乎统计独立（Spearman rho = -0.026）。智能体读取的文档中，大约三分之一在因果上承载作用，但对静态阅读器来说似乎无用；我们称这些为桥接文档。当用BM25和交叉编码器代理替换基于阅读器的轴时，这种模式仍然存在，在均匀分布的轴上桥接单元占比27.2%。第二个实验确定了机制。使用先前工作中提出的可观测实体相关性（OER）度量，区分相关与不相关候选实体的实体出现在智能体下一查询中的频率，是仅出现在不相关文档中实体的4.02倍（6.1% vs 1.5%, n = 227,139）。桥接文档通过向智能体提供改变搜索方向的区分性实体来证明其价值。在智能体检索中，静态相关性和因果有用性是不同量，优化前者并不能带来后者。

## Abstract
Retrieval systems are trained and evaluated on a static idea of usefulness: hand a document and a question to a reader model, see whether the answer improves, and score the document accordingly. The idea holds up when a document is read on its own. It breaks when a language model works as a search agent, issuing several queries and reasoning across turns, because a document can matter for what it lets the agent do next rather than for what it says about the current question.   We measure that gap rather than argue it. Using a ReAct style agent over HotpotQA, we replay 1000 development questions and, for every document the agent read, delete it and re-run the rest of the trajectory from that point. Comparing the original run against its counterfactual gives a Counterfactual Trajectory Utility (CTU) score from three deltas: final answer quality, next query retrieval quality, and turn count. Crossing CTU against Static RAG Utility (SRU) over 23,322 document observations, the two are close to statistically independent (Spearman rho = -0.026). Roughly a third of the documents the agent reads are causally load bearing while looking useless to a static reader; we call these bridge documents. The pattern survives when the reader based axis is swapped for a BM25 and cross encoder proxy, giving a bridge cell of 27.2% on an evenly spread axis.   A second experiment pins down the mechanism. Using the Observable Entity Relevance (OER) measure from prior work, entities that discriminate relevant from non-relevant candidates appear in the agent's next query 4.02 times more often than entities found only in non-relevant documents (6.1% vs 1.5%, n = 227,139). A bridge document earns its keep by handing the agent a discriminative entity that redirects the search. Static relevance and causal usefulness are different quantities in agentic retrieval, and optimizing the first does not deliver the second.

## 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：传统检索系统基于“静态有用性”（static utility）评估文档——将文档和问题一起交给阅读器，看答案是否改善。但在多步智能体搜索（如ReAct Agent）中，智能体会发出多个查询、跨步推理，文档的价值可能不在于直接包含答案，而在于它**能让智能体下一步做什么**（例如提供关键实体以引导后续搜索）。这种“因果有用性”（causal utility）与静态有用性不同。
- **整体含义**：当前检索系统（训练和评估均基于静态指标如nDCG、MAP、MRR）可能无法服务于agentic retrieval。论文通过反事实实验量化了这一差距，发现二者几乎独立（Spearman ρ = -0.026），约三分之一的文档是“桥接证据”（bridge evidence）：静态评估无用，但因果上不可或缺。这提示需要重新设计针对智能体场景的检索评估与优化目标。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程
### 2.1 核心思想
- 使用**反事实轨迹探索（Counterfactual Trajectory Exploration, CTE）**：对于智能体实际读取的每个文档，在轨迹中将其删除，然后从该点重放后续轨迹（保持前缀不变），比较原始轨迹与反事实轨迹的表现。
- 定义**反事实轨迹效用（Counterfactual Trajectory Utility, CTU）**，由三个delta组成：
  - Δanswer：最终答案F1的变化（base minus counterfactual）
  - Δnext-query：下一检索查询的nDCG@10变化
  - Δeffort：所需轮次数的变化（counterfactual minus base）
- 三个delta分别进行min-max归一化后等权求和：CTU = w1·Δanswer_norm + w2·Δnext-query_norm + w3·Δeffort_norm，w1=w2=w3=1。
- **零点意义**：当所有delta为0时，CTU = 1.4，恰好对应“无因果效应”点。大于1.4表示文档有帮助，小于1.4表示删除后反而更好。

### 2.2 关键技术细节
- **Agent**：ReAct风格，使用Qwen2.5-7B-Instruct，温度=0，采样关闭，确定性解码。
- **检索栈**：第一段BM25（段落级Wikipedia索引），top50由交叉编码器重排序，最后top10呈现给智能体。文档去重：已显示文档不再重复显示。
- **静态RAG效用（SRU）**：用同一个阅读器（Qwen2.5-7B）分别在有文档和无文档条件下回答，计算F1差值ΔSRU = F1(with_doc) - F1(without_doc)。负值表示文档不如无文档。
- **实体传播机制**：使用可观测实体相关性（OER）度量，基于HotpotQA支持事实，计算实体在候选集合中的区分度（logit差乘以支持度权重）。高OER实体（在至少一个相关文档中出现且OER>0）与低OER实体（在相关文档中从未出现）的传播率对比。

### 2.3 算法流程（文字说明）
1. 对HotpotQA开发集进行分层抽样（覆盖过滤+比例分配），获得1000个问题。
2. 运行ReAct Agent获取原始轨迹日志（包括每步的查询、显示文档、答案、下一查询）。
3. 对每个轨迹中的每步每个显示文档执行反事实干预：在候选列表删除该文档（从top10中移除），重新运行从该步开始的轨迹，保持前缀不变。
4. 计算CTU的三个delta（答案F1变化、下一查询nDCG@10变化、轮次变化）。
5. 对同一文档计算SRU（通过独立阅读器在有/无文档时的F1增量）。
6. 构建象限图：CTU按1.4阈值分割高低，SRU按0分割高低（ΔSRU>0为高）。得到四个单元格：期望有用、冗余、桥接、真正无用。
7. 进行实体传播分析：提取每步实体，链接到WAT实体链接器，计算OER，测量高/低OER实体出现在下一查询中的比例。

## 6. 主要结论与发现
1. **静态效用与因果效用几乎独立**：SRU与CTU的Spearman ρ = -0.026（总样本），替换为BM25+交叉编码器代理后ρ = -0.016（不显著）。
2. **桥接文档大量存在**：35.72%的文档（读者轴）和27.16%（代理轴）属于“静态评估无用但因果关键”的桥接单元格，远超预设的20%阈值。
3. **机制：桥接文档提供区分性实体**：高OER实体出现在Agent下一查询中的概率是低OER实体的4.02倍（6.1% vs 1.5%，精确匹配标准）。该结果在飞行员和全样本上稳定，且卡方检验p < 1e-300。
4. **H2未确认**：高OER实体是否定位在桥接文档中？实验未能在更大样本中复现（方向反转且统计力不足），因此未声称此假设成立。
5. **轮次数趋势是伪效应**：桥接比例随反事实轮次增加而增加，但此变量与CTU中的effort项机械相关（confunding），作者主动撤回该趋势解读。

## 7. 优点：方法与实验亮点
- **反事实干预直接测量因果作用**：CTE通过逐个删除文档并重放轨迹，提供了干净的反事实因果推断，避免了相关性推断的混淆。
- **CTU零点有理论依据**：当文档无任何因果效应时，三个delta全为零，CTU恰好为1.4，因此阈值有原则性定义而非任意截断。
- **机制解释有力**：将桥接文档与实体区分性（OER）联系起来，提供了从静态实体相关性到智能体行为转移的可解释链条。此连接是机械性的，而非仅相关性。
- **严谨性**：主动报告了静态轴的偏斜、代理轴的数据排除、H2未复现、轮次趋势的混淆，并限制结论范围。公开了System Prompt、Reader Prompt等实验设置。
- **鲁棒性验证**：用BM25+交叉编码器代理替代阅读器轴后，桥接单元仍显著（27.16%），说明结果不是由弱阅读器导致的。

## 8. 不足与局限
### 8.1 实验覆盖
- **仅单一Agent模型**：所有结果基于Qwen2.5-7B-Instruct，不同模型（如GPT-4、LLaMA 70B）可能有不同行为。未测试模型迁移性。
- **仅单一数据集**：HotpotQA是段落级多跳QA，其他领域（如对话、代码搜索）或类型（长文档、混合源）未知。
- **仅单一检索栈**：BM25+交叉编码器，未测试dense retrieval或混合检索。
- **静态轴偏斜**：仅3.30%的观测ΔSRU>0，读者表现极弱（平均F1 0.0170）。桥接单元格比例很大程度上是独立性在偏斜边际下的推算，而不是独立发现。代理轴排除了58.84%的观测（两个检索信号不一致），这些记录的桥接情况未知。

### 8.2 偏差风险
- **确定性假设近似**：温度0和采样关闭不能保证严格确定性，残余噪声可能影响个体CTU观测，但大数据量下平均效应可信。
- **OER池小**：每步仅有2-6个相关段落，OER估计噪声较大，但效应仍显著。
- **轮次趋势的confounding**：论文已识别并撤回，但早期读者可能误读为“桥接证据随难度增加”的结论。
- **H2未确认**：无法确定桥接文档是否特异性地指向传播实体的来源，减弱了“桥接文档=实体传播关键载体”的叙事。

### 8.3 应用限制
- CTU计算成本极高（需要每个文档一次完整轨迹重放），无法直接用于训练循环。论文承认需要近似代理。
- 静态效用和因果效用独立这一结论可能仅在多步推理场景中成立，对于单步问答仍可能使用静态指标。
- 实体传播分析依赖于WAT实体链接器，对语言和小实体可能不稳定。
