## 摘要
训练工具使用型代理从自身经验中改进仍然具有挑战性，因为监督微调依赖于固定的教师蒸馏轨迹，而稀疏奖励强化学习为长程交互提供的监督信号较弱。我们提出DeepSearch-Evolve，一个基于DeepSearch-World构建的Web代理自我蒸馏框架。DeepSearch-World是一个确定且可验证的环境，配备可复现的搜索和页面阅读工具。该环境包含42万个基于实体级随机游走构建的多跳问答任务，并支持关键的代理认知行为（如进度验证、基于经验的反思和失败恢复），这些行为有助于自我进化。DeepSearch-Evolve通过迭代进行轨迹生成、过滤、数据混合和微调来训练更强的代理。无需从更强大的模型中蒸馏，DeepSearch-World-9B在与开源代理的竞争中取得了有竞争力的性能：在BrowseComp上达到31.2%，在GAIA上达到61.5%，在HotpotQA上达到93.4%，这表明可验证环境能够实现长程Web代理的可扩展自我进化。我们将发布环境、42万训练池、验证集、模型和代码，以促进未来深度搜索代理自我改进研究。

## Abstract
Training tool-use agents to improve from their own experience remains challenging, as supervised fine-tuning relies on fixed teacher-distilled trajectories, while sparse-reward reinforcement learning provides weak supervision for long-horizon interactions. We present DeepSearch-Evolve, a self-distillation framework for web agents built on DeepSearch-World, a deterministic and verifiable environment with reproducible search and page-reading tools. DeepSearch-World contains 420K multi-hop QA tasks constructed from entity-level random walks and supports key agentic cognitive behaviors useful for self-evolving, including progress verification, grounded reflection, and failure recovery. DeepSearch-Evolve iteratively performs trajectory generation, filtering, data mixing, and fine-tuning to train stronger agents. Without distillation from more capable models, DeepSearch-World-9B achieves competitive performance compared with open-source agents, reaching 31.2% on BrowseComp, 61.5% on GAIA, and 93.4% on HotpotQA, showing that verifiable environments enable scalable self-evolution for long-horizon web agents. We will release the environment, 420K training pool, validation set, model, and code to facilitate future research on self-improving deep search agents.

当前训练工具使用型智能体（如Web搜索代理）面临关键挑战：监督微调（SFT）依赖固定的教师蒸馏轨迹，智能体性能易饱和；而强化学习（RL）使用稀疏的最终奖励，难以对长程交互中的中间步骤（如查询构建、工具选择、证据提取）提供有效指导。现有自进化方法受限于静态模仿信号、稀疏结果奖励或不可靠的密集监督。本文提出一种可验证的确定性环境（DeepSearch-World）和自蒸馏框架（DeepSearch-Evolve），使得智能体能够从自己生成的、经过验证的工具使用经验中迭代改进，无需依赖更强大的外部教师模型。

## 2. 方法论：核心思想、关键技术细节
### 核心思想
构建一个确定且可验证的离线环境（基于Wikipedia知识图谱和实体级随机游走生成的42万个多跳QA任务），在该环境中环境可以提供实体级的过程验证信号（如进度追踪、接地反思、失败恢复）。利用脚手架教师代理生成高质量轨迹，然后通过过滤、格式转换（脚手架→ReAct）、数据混合和SFT训练，迭代提升学生代理能力。

### 关键技术细节
- **可验证环境 DeepSearch-World**：基于Wikipedia离线语料库（约1000万条目），提供两个确定性的工具：`web_search_wiki`（BM25检索，返回标题+摘要+URL）和`visit_wiki`（通过SQLite偏移索引获取全文）。环境存储每题的ground-truth实体集，在工具调用后自动检测是否匹配未解决实体，提供无LLM判断的进度验证。
- **脚手架教师代理（三阶段）**：
  - **Plan**：初始化结构化进度状态（completed_list, todo_list, experience, information）。
  - **Act**：最多Tmax步，调用工具，更新状态，环境注入接地反思（失败时逐步增强指导）。
  - **End**：当证据足够时生成基于已验证记忆的简洁答案。
- **自进化训练循环**：
  - 每轮使用当前模型πθ_R生成脚手架轨迹。
  - 保留答案正确的轨迹，再通过Qwen3.5-9B进行轨迹级质量过滤（清除冗余、弱对齐、不一致）。
  - 将过滤后的脚手架轨迹转换为ReAct格式：将进度状态和反思重写为`<think>`块中的推理和自我纠错，保持`<action>`和`<observation>`不变。
  - 使用SFT更新学生模型πθ_{R+1}，损失函数为负对数似然（等价于硬标签token级蒸馏）。
  - 重要性采样混合多轮数据，衰减因子γ=0.5，优先近期数据但保留早期以防遗忘。
  - 最后在1600个真实工具实例上进行GRPO微调以减少离线到真实执行的差距。

## 6. 主要结论与发现
- **可验证环境能实现长程Web智能体的可扩展自我进化**，无需依赖更强模型蒸馏。
- DeepSearch-World-9B相对于骨干模型Qwen3.5-9B显著提升：BrowseComp +23.8、GAIA +37.6、HotPotQA +48.1。
- **数据池多样性**是自我进化的关键：420K池比100K池更早饱和，且性能更高、波动更小。
- **脚手架→ReAct转换**和**环境反思重写**是核心：移除反思重写导致性能大幅下降。
- 拒绝采样比质量过滤贡献更大，两者组合最佳。
- 进化SFT比全在线策略蒸馏（OPSD）和Skill-SD更稳定有效。

## 7. 优点（亮点）
- 提出**可验证的确定性环境**（DeepSearch-World），提供实体级过程信号，无需LLM判断，使长程工具使用轨迹可复现、可验证。
- **脚手架教师代理**设计巧妙：三阶段规划-行动-结束，结合环境接地反思，使得代理学到规划、记忆、纠错等高级认知行为，并能通过蒸馏注入学生。
- **异步生成-训练循环**：生成不阻塞训练，支持大规模迭代，效率高。
- **无需外部更强教师**：仅从自身验证轨迹中蒸馏即可持续提升，挑战了依赖外部蒸馏的范式。
- 代码、环境、数据集、验证集、模型均将开源，促进社区研究。

## 8. 不足与局限
- **环境领域局限**：仅基于Wikipedia，覆盖知识有限，不能泛化到实时网络或多种数据源（如新闻、PDF、专有数据库）。
- **更新规则局限**：采用进化SFT而非RL或OPSD，可能限制对更高层能力的注入（如规划、纠错策略的强化学习）。
- **语言局限**：训练全英文轨迹，导致中文基准（BrowseComp-ZH）提升较小，跨语言迁移有限。
- **偏差风险**：Wikipedia内容可能包含社会偏见，模型可能继承；环境基于随机游走构建，可能偏向常见实体。
- **实验泛化性**：仅在Qwen3.5-9B一个骨干上验证，未测试不同架构或更大规模模型；未对比RL-only方案（如GRPO）在同等设置下的效果。
- **离线到在线迁移**：虽然通过少量GRPO微调缓解，但差距未完全消除；工具架构虽对齐真实Web，但BM25索引与真实搜索引擎行为仍有差异。
- **消融实验**：未单独评估动画步数和不同过滤阈值的影响；高级能力评分基于LLM法官，可能不够客观。
