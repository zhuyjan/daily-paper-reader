## 摘要
长视域语言代理不仅选择动作；它们还会在决策之间携带私有的世界模型。当该模型发生偏移时，后续的失败可能在执行失败动作之前就已经注定。我们研究了一种直接的修复机制：在承诺执行下一个任务动作之前，代理可以向环境询问一个信念字段，并将答案写回其世界模型。这使得环境交互成为一种稀缺的校准资源，而不仅仅是推进任务的方式。我们引入了\method，一种用于结构化信念表的预算化探测算子。有用的探测并非处处相同。程序性信念（如工具依赖关系）通常可以通过针对性检查来修复，但这些检查会消耗任务可能需要的步骤。空间性信念（如物体位置和图边缘）更多依赖结构线索；当世界在屏幕外发生变化时，代理自身的信心可能是一个糟糕的指南。一种分层类型分析形式化了这种探测-动作边界，受控实验表明，当探测策略遵循任务结构时，规划中的环境证据能够减少终端世界模型误差。

## Abstract
Long-horizon language agents do not only choose actions; they carry a private model of the world from one decision to the next. When that model drifts, a later failure can be decided before the failing action is ever taken. We study a direct repair mechanism: before committing to the next task action, an agent may ask the environment about one belief field and write the answer back into its world model. This makes environment interaction a scarce calibration resource, not merely a way to advance the task. We introduce \method, a budgeted probing operator for structured belief tables. The useful probes are not the same everywhere. Procedural beliefs, such as tool dependencies, can often be repaired by targeted checks, but those checks spend steps that the task may need. Spatial beliefs, such as object locations and graph edges, rely more on structural cues; the agent's own confidence can be a poor guide when the world changes off-screen. A type-stratified analysis formalizes this probe-action frontier, and controlled experiments show that mid-planning environment evidence reduces terminal world-model error when the probe policy follows the structure of the task.

- **问题**：长视域语言智能体在决策间维护内部世界模型（structured belief table），但该模型会随时间漂移（drift），导致后续决策基于过时信息而失败。这种失败往往在看似合理的局部推理之后才显现。
- **背景**：现有智能体（如ReAct、Reflexion、LATS）通过推理-行动-观察循环更新状态，但未将环境交互视为一种**预算受限的校准资源**，即每次探查（probe）会消耗任务动作的步骤。由此产生了信息价值与任务推进的权衡。
- **核心含义**：将环境重查询从“推进任务”的附属行为提升为一种**主动的、预算化的世界模型维护操作**，并研究不同信念类型（程序性 vs 空间性）下探针策略的有效性。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 引入**预算化环境探针**（EnvProbe），在每次规划步骤前，根据评分函数选择最可能已漂移且关键的信念字段，向环境查询其真实值，更新世界模型。探针的预算为 \( B = \lfloor H/4 \rfloor \)（H为总步数）。

### 关键技术细节
- **信念类型分类**：
  - **程序性信念**（\(F_{proc}\)）：工具依赖、子目标完成、库存等动作依赖状态。
  - **空间性信念**（\(F_{spat}\)）：物体位置、门状态、图边等外生状态。
- **评分函数**：
  \[
  \rho_i(t) = c_i + s_i(t) + u_i(t) + d_i(t)
  \]
  - \(c_i\)：关键性（任务权重归一化）
  - \(s_i(t)\)：LLM报告的陈旧度（\(\min(1, \hat{\tau}_i/10)\)）
  - \(u_i(t)\)：言语化不确定性（\(1 - \text{conf}_i\)）
  - \(d_i(t)\)：依赖性角色（直接阻塞/传递依赖/无关，取0,0.5,1）
- **两类信号**：
  - **结构部分**：\(c_i + d_i(t)\)，来自任务图和下一步动作的依赖关系。
  - **自我报告部分**：\(s_i(t) + u_i(t)\)，来自模型自身的记忆和置信度。

### 算法流程（EnvProbe-Simple，贪婪阈值策略）
1. 初始化信念表 \(b_0 = g_0\)，预算 \(B\)。
2. 每一步：对每个字段计算 \(\rho_i(t)\)。
3. 若最大 \(\rho_i(t) \ge 1.5\) 且预算未耗尽，则探查该字段（调用PROBE API），更新信念，预算减1。
4. 否则执行任务动作。
5. 重复直至步数达到H。

## 6. 论文的主要结论与发现

1. **探针能修复世界模型**：EnvProbe-Simple相比Periodic-Probe在程序性任务上提升WSA +11.76 pp，全集合平均+6.45 pp；空间性增益较小（+3.79 pp）但仍显著。
2. **结构线索是主要驱动力**：移除关键性（\(c_i\)）或依赖性（\(d_i\)）导致WSA大幅下降，证明它们是负载承载项；移除陈旧度（\(s_i\)）影响微弱；移除不确定性（\(u_i\)）反而提升WSA（+5.76 pp），但任务成功率下降，揭示不确定性作为反信号。
3. **程序性与空间性不对称**：程序性任务中探针-动作存在明显Pareto前沿；空间性任务中（c+d）版本同时优于WSA和任务成功率，前沿几乎消失。
4. **言语化置信度不可靠**：自我报告的高置信度错误概率\(\hat{p}_{\text{cw}}=0.94\)，导致Uncertainty-only策略天然漏掉多数需修复字段（Proposition 5.5验证）。
5. **理论边界成立**：基于子模性的信念修复下界、自我报告扰动界、预算位移界均与实验趋势一致。

## 8. 不足与局限
