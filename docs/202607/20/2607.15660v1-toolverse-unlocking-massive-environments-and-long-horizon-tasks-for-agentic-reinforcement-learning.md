## 摘要
虽然LLM智能体在紧凑且定义良好的场景中表现出强大的推理能力，但在需要无缝工具集成的大规模、多样化和动态的真实世界环境中，它们难以保持稳健性和有效性。为了弥补这一差距，我们引入了ToolVerse，一个全面的框架，用于扩展智能体强化学习环境，并使智能体能够在工具集成推理（TIR）任务中执行复杂的长期推理。首先，ToolVerse从近400个真实世界模型上下文协议（MCPs）中自动构建大规模可执行的智能体训练环境，这些协议包含约4500个工具。其次，我们提出了一种基于工具依赖图的任务设计策略，利用动态解锁采样算法生成长期任务，并生成GUST（图解锁采样任务）数据集。第三，为了缓解长期智能体强化学习中的信用分配问题，我们提出了一种细粒度的回合感知相对优势算法。我们使用ToolVerse进行了广泛的智能体强化学习训练，并在几个智能体基准上评估了我们的框架。实验结果表明，我们的框架显著增强了LLM在长期工具使用中的能力，实现了显著的性能提升，并展示了在动态环境中的稳健推理。

## Abstract
While LLM agents demonstrate strong reasoning abilities in compact and well-defined scenarios, they struggle to maintain robustness and effectiveness when faced with large-scale, diverse, and dynamic real-world environments that demand seamless tool integration. To address this gap, we introduce ToolVerse, a comprehensive framework that scales up agentic RL environments and enables agents to perform complex long-horizon reasoning in Tool-Integrated Reasoning (TIR) tasks. First, ToolVerse automatically builds the massive executable agent training environments from nearly 400 real-world Model Context Protocols (MCPs) that contain about 4500 tools. Second, we propose a task design strategy based on a tool dependency graph, utilizing Dynamic Unlocking Sampling Algorithm to generate long-horizon tasks, and produce GUST (Graph Unlocking Sampling Tasks) dataset. Third, to alleviate the credit assigment problem in long-horizon agentic RL, we propose a fine-grained Turn-Aware Relative Advantage algorithm. We conduct extensive Agentic RL training using ToolVerse and evaluate our framework on serveral agentic benchmarks. Experimental results demonstrate that our framework significantly strengthens LLMs' capabilities in long-horizon tool use, achieving a marked performance boost and showcasing robust reasoning within dynamic environments.

  - **环境多样性不足**：现有智能体强化学习（Agentic RL）环境通常仅支持少量工具（如代码解释器、搜索引擎），缺乏真实世界中多样化的结构化API交互。
  - **任务设计困难**：设计多轮、长期推理且涉及多个工具集成的任务需要复杂规划，现有方法难以生成逻辑一致的长序列。
  - **信用分配问题**：在长序列轨迹中，稀疏的终端奖励无法为中间动作提供有意义的优势估计，导致策略梯度方差高、训练不稳定。
- **整体目标**：提出ToolVerse框架，通过规模化可执行环境、图引导的长期任务生成以及细粒度回合感知优势估计，全面提升LLM在工具集成推理中的能力。

## 2. 方法论：核心思想、关键技术细节

### 2.1 规模化可执行智能体环境构建
- **自动化管线**：从原始工具定义（约422个MCP环境，包含约4438个工具）出发，经历以下步骤：
  1. **模式重构（Schema Refactoring）**：清理原始模式中的噪声，标准化函数签名。
  2. **领域字典数据库构建**：为每个工具集建立轻量级模拟数据库（状态变量如库存、用户档案）。
  3. **可执行函数生成**：基于MCP工具库生成Python函数，实现数据库查询/更新。
  4. **单元测试验证**：自动生成单元测试，仅保留通过所有语法和测试的工具集。
- 最终获得超过400个可执行工具环境，每个环境包含5-20个工具，覆盖8个大领域。

### 2.2 基于图引导的长期任务合成（GUST数据集）
- **工具依赖图（TDG）构建**：对于每个场景，构建有向无环图G=(V,E)，节点为工具，边表示依赖关系（输入输出依赖或逻辑顺序）。使用LLM辅助推断，并经过环检测与清理。
- **动态解锁采样算法（DUS）**：
  - 维护一个就绪队列Q，包含当前入度为0的节点。
  - 每步从Q中采样一个子集St（批大小k = min(|Q|, N)），作为轨迹的一个阶段。
  - 执行St后，更新后继节点的入度，将入度变为0的节点加入Q。
  - 重复直到Q为空，得到多阶段轨迹T = [S1, S2, ..., Sm]。
  - 该拓扑顺序保证了任务复杂度的自然递进。
- **逆向上下文重建**：将DUS输出的工具骨架实例化为可执行的Golden Trace。依赖参数从前序工具输出填充，上下文参数从当前数据库状态检索。再通过LLM将每个Golden Trace转换为用户面对的自然语言任务。最后经过LangGraph执行验证和教师智能体Pass@8过滤，确保任务可执行且逻辑一致。最终获得2987个数据项，平均每个项目包含3.8个子任务。

### 2.3 回合感知相对优势估计（TARA）
- **问题**：标准GRPO对整个轨迹赋予单一优势，无法区分正确中间步骤和后续错误。
- **核心思想**：利用Golden Trace提供每轮的工具调用真值，分解优势为两部分：
  - **局部优势（Alocal）**：基于二进制奖励ri,t（当前工具调用是否覆盖Golden Trace中的JSON对象），在组内归一化。
  - **门控未来优势（Afuture）**：计算门控未来价值Vi,t = δi,t · Σγ^k r_{i,t+k+1}，其中δi,t = ri,t作为一致性门，确保只有当前步正确时才传播未来奖励。归一化后得到Afuture。
  - **总优势**：Atotal = Alocal + λ·Afuture，默认λ=0.5。
- **理论分析**：证明TARA能降低优势估计方差（λ<1时），且能抑制干扰动作（distractor）的正虚假信用——对无效动作，总优势严格非正，从而抑制其概率。
- **实现细节**：每轮根据组内方差处理零方差情况（若所有rollout相同，设归一化优势为0）。
