## 摘要
现有的长周期LLM代理记忆系统通常将先前的轨迹作为被动上下文检索，而不是将其转化为可执行的能力。本文提出MSCE，一种无需训练的记忆-技能协同进化框架，将代理经验组织为有根据的步骤轨迹、可重用的程序性策略和陈述性环境认知。MSCE将具有正向估计收益的证据支持的L2策略结晶为可调用的技能，这些技能保留证据链接、适用边界、决策指导、验证规则和可靠性估计。此外，它引入了反思加权价值回溯填充，通过密集的局部自我反思传播稀疏的终端反馈，产生经过证据校准的轨迹价值，用于管理记忆和技能进化。在EvoAgentBench和LoCoMo上的实验表明，MSCE显著优于最先进的技能增强和记忆驱动代理基线，展现出强大的跨领域迁移能力和终身进化能力。

## Abstract
Existing memory systems for long-horizon LLM agents often retrieve prior traces as passive context rather than converting them into executable capabilities. In this paper, we propose MSCE, a training-free Memory--Skill Co-Evolution framework that organizes agent experience into grounded step traces, reusable procedural policies, and declarative environmental cognition. MSCE crystallizes evidence-backed L2 policies with positive estimated gain into callable skills that retain evidence links, applicability boundaries, decision guidance, verification rules, and reliability estimates. It further introduces reflection-weighted value backfilling, which propagates sparse terminal feedback through dense local self-reflections to produce evidence-calibrated trace values for governing memory and skill evolution. Experiments on EvoAgentBench and LoCoMo demonstrate that MSCE significantly outperforms state-of-the-art skill-augmented and memory-driven agent baselines, exhibiting strong cross-domain transferability and lifelong-evolution capabilities.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：现有LLM代理的记忆系统主要存储原始交互日志或经验总结，但存在两个关键缺陷：一是记忆仅作为被动上下文被检索，代理每次仍需重新推理；二是直接从噪声轨迹中提取技能容易过拟合且缺乏适应性。这导致代理在长周期、多步骤任务中效率低下，无法持续自主进化。
- **核心问题**：如何实现从被动记忆到可执行技能的转化？如何将稀疏的终端反馈与密集的局部自省信号结合，以可靠地评估每一步价值并驱动记忆和技能的协同进化？
- **整体目标**：提出一个无需微调（training-free）的框架，使LLM代理能够将交互经验组织为证据可追溯的记忆层级，并将高收益策略自动结晶为可调用的技能，实现跨域迁移和终身学习。

## 2. 方法论

### 核心思想
MSCE通过三层级记忆体系（L1轨迹、L2策略、L3环境认知）将经验抽象化，并引入反思加权值回填（reflection-weighted value backfilling）从稀疏终端反馈中校准每步价值，进而将支持证据充足、正向收益且稳定的L2策略“结晶”为可部署的技能。

### 关键技术细节

- **三层记忆层级**：
  - **L1轨迹记忆**：存储每一步的原子证据 `(state, action, observation, self-reflection, trace value)`，作为证据层。
  - **L2策略记忆**：从跨回合轨迹中归纳重复出现的流程模式，包含触发条件、自然语言步骤、验证规则、适用边界以及支持证据集。
  - **L3环境认知记忆**：抽象关于环境结构、约束和规则性的陈述性知识，链接到支持它的L2策略。

- **反思加权值回填**：
  - 终端反馈 `R_i` 分配给最后一步，之前步骤的值通过公式 `V(f_{i,t}) = α_{i,t} * R_i + (1 - α_{i,t}) * γ * V(f_{i,t+1})` 计算，其中 `α` 由LLM根据自省的质量（ faithfulness, causal insight, transferability, concreteness ）评估得到。
  - 高 `α` 步骤能独立贡献反馈信息，低 `α` 步骤主要继承后续价值。

- **技能结晶与调用**：
  - L2策略需满足支持证据保留、正向增益（ `G > θ_G` ）以及稳定性（最近证据未导致大幅重写）才可被结晶为技能。
  - 技能包含调用接口、证据锚点、决策指导和可靠性估计 `η`，部署后通过平滑成功率动态更新可靠性。
  - 推理时按层级检索：先匹配技能触发器，若失败则退回到L1轨迹和回合级检索。

- **在线更新流程**：一个回合结束后，异步执行L1持久化、值回填、L2关联/归纳、L3抽象、技能结晶/验证，并由失败爆发或用户修正触发决策指导更新。
