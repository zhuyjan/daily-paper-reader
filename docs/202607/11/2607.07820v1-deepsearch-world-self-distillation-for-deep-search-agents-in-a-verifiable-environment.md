## 摘要
训练工具使用代理从自身经验中改进仍然具有挑战性，因为监督微调依赖于固定的教师蒸馏轨迹，而稀疏奖励强化学习则为长周期交互提供了较弱的监督。我们提出了DeepSearch-Evolve，一个基于DeepSearch-World构建的Web代理自我蒸馏框架，DeepSearch-World是一个确定性且可验证的环境，具有可复现的搜索和页面阅读工具。DeepSearch-World包含了基于实体级随机游走构建的42万条多跳问答任务，并支持对自我进化有用的关键代理认知行为，包括进度验证、基于事实的反思和失败恢复。DeepSearch-Evolve通过迭代执行轨迹生成、过滤、数据混合和微调来训练更强的代理。在没有更强大模型蒸馏的情况下，DeepSearch-World-9B在与开源代理的竞争中达到了有竞争力的性能，在BrowseComp上达到31.2%，GAIA上达到61.5%，HotpotQA上达到93.4%，这表明可验证环境能够实现长周期Web代理的可扩展自我进化。我们将发布环境、42万训练集、验证集、模型和代码，以促进未来对自我改进深度搜索代理的研究。

## Abstract
Training tool-use agents to improve from their own experience remains challenging, as supervised fine-tuning relies on fixed teacher-distilled trajectories, while sparse-reward reinforcement learning provides weak supervision for long-horizon interactions. We present DeepSearch-Evolve, a self-distillation framework for web agents built on DeepSearch-World, a deterministic and verifiable environment with reproducible search and page-reading tools. DeepSearch-World contains 420K multi-hop QA tasks constructed from entity-level random walks and supports key agentic cognitive behaviors useful for self-evolving, including progress verification, grounded reflection, and failure recovery. DeepSearch-Evolve iteratively performs trajectory generation, filtering, data mixing, and fine-tuning to train stronger agents. Without distillation from more capable models, DeepSearch-World-9B achieves competitive performance compared with open-source agents, reaching 31.2% on BrowseComp, 61.5% on GAIA, and 93.4% on HotpotQA, showing that verifiable environments enable scalable self-evolution for long-horizon web agents. We will release the environment, 420K training pool, validation set, model, and code to facilitate future research on self-improving deep search agents.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：训练工具使用型大语言模型代理（如网络搜索代理）从自身交互经验中持续改进非常困难。现有方法主要有两种：监督微调（SFT）依赖固定教师蒸馏轨迹，性能易饱和；稀疏奖励强化学习（RL）在长周期交互中难以提供细粒度监督，无法区分失败来源（如查询 formulation、工具选择、证据提取等）。
- **整体含义**：作者提出通过构建一个**确定性且可验证的环境**（DeepSearch-World），使代理能够获得过程级的密集监督信号（如进度验证、基于事实的反思、失败恢复），进而实现可扩展的自我进化。这为无需依赖更强模型蒸馏、仅靠自生成经验提升代理能力提供了新路径。

## 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：提出**DeepSearch-Evolve**，一种基于确定性可验证环境的自我蒸馏框架。通过迭代执行“轨迹生成 → 拒绝采样与质量过滤 → 数据混合 → SFT微调”，使代理从自身经过验证的工具使用经验中学习。
- **关键技术细节**：
  - **DeepSearch-World环境**：基于Wikipedia离线语料的确定性环境，提供`web_search_wiki`（BM25检索，返回标题、摘要和URL）和`visit_wiki`（SQLite索引映射URL至全文）两个工具。每个问题关联一个隐藏目标实体集，环境可在每次工具调用后自动验证是否命中未解析实体，提供过程级反馈。
  - **脚手架教师代理（Scaffold Teacher Agent）**：采用三阶段流程——**Plan**（初始化结构化进度状态）、**Act**（迭代执行工具调用，利用环境反思更新状态）、**End**（基于已验证工作记忆生成答案）。该教师代理仅用于轨迹生成，不暴露给学生。
  - **Scaffold-to-ReAct转换**：将教师轨迹中的进度状态、环境反思等改写为学生可用的`<think>`块（`<think>_t = P_t ⊕ R_t ⊕ A_t`），保留动作和观察，训练标准的ReAct策略。
  - **自进化训练循环**：每轮当前模型作为教师生成轨迹，通过答案正确性验证（拒绝采样）和轨迹质量过滤保留成功轨迹，再转化为ReAct格式进行SFT更新。不同轮次数据采用重要性采样混合（衰减因子γ=0.5）。
  - **训练目标**：SFT最小化交叉熵损失，等价于硬标签token级策略蒸馏。

## 6. 论文的主要结论与发现
- **主要结论**：DeepSearch-World-9B通过自身验证轨迹的自我蒸馏，在多个深度搜索基准上显著超越骨干模型Qwen3.5-9B-Instruct（提升+23.8% ~ +48.1%），且与依赖更强模型蒸馏的开源代理竞争，证明了确定性可验证环境能替代部分外部强监督。
- **关键发现**：
  - 数据池规模至关重要：420K训练池比100K导致更高的验证性能、更低的格式错误、更稳定的工具成功率和实体命中率。
  - 反思重写（将环境反馈改写为学生自我纠正）和状态内化（注入规划/记忆）对性能提升贡献显著。
  - 代理学会了更长的交互（平均18.0轮 vs. 骨干4.7轮）、更有效的访问调用（5.4次 vs. 0.9次）、更高的高级能力评分（70% vs. 19%）。

## 7. 优点
- **环境设计**：DeepSearch-World提供确定性、可复现、过程可验证的交互，支持实体级进度验证和规则化反思，无需昂贵LLM判断。
- **方法论创新**：Scaffold-to-ReAct转换将教师的高质量规划、记忆、错误恢复等认知行为无缝植入标准ReAct策略，无需修改推理框架。
- **可扩展性**：迭代自我蒸馏不依赖更强模型，仅从自身验证经验中提升，避免对专有模型依赖。
- **充分消融与分析**：通过数据规模效应、行为分析、消融实验等多角度验证了方法有效性。
- **开源贡献**：将开源环境、42万训练集、验证集、模型和代码，促进后续研究。

## 8. 不足与局限
- **环境局限**：当前环境仅基于Wikipedia，领域覆盖有限，可能影响泛化到其他知识源（如实时新闻、专业数据库）。
- **训练策略局限**：目前使用SFT更新，作者声称RL或OPSD可能进一步提高，但如何将高层能力（规划、错误恢复）注入RL训练尚未探索。
- **离线到在线差距**：虽然用GRPO微调了1600个真实工具实例，但主要实验仍在离线环境进行，真实Web的噪声、动态性未充分评估。
- **对比公平性**：对比的开源代理并非全部严格9B参数（包含7B-8B），且部分使用了更强模型蒸馏，因此性能比较更偏向“方法有效性”而非“绝对最优”。
- **偏差风险**：数据源自Wikipedia，可能包含社会偏见，模型可能继承此类偏见，安全性对齐需进一步研究。
- **可复现性细节**：虽提供了超参数，但未提供完整代码库（仅声明将开源），当前复现仍有难度。
