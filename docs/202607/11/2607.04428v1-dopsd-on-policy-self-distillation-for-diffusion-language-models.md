## 摘要
扩散大语言模型（dLLMs）通过迭代去噪掩码序列来生成文本，为自回归模型提供了一种并行替代方案，但通过后训练激发强推理能力仍然困难：监督微调是离策略的，并且存在曝光偏差，而强化学习仅提供稀疏的序列级奖励，且在缺乏可处理序列似然的情况下难以应用。在策略自蒸馏（OPSD）提供了一种有前景的替代方案，使用同一个模型既作为学生又作为教师，提供密集的、令牌级的、在策略的监督，但其有效性依赖于给教师特权信息（PI）——通常是推理时不可用的实例特定真实参考——因此学生最终蒸馏出的是一种弱的不含特权信息的共识策略，对dLLM推理几乎没有改进。我们提出了dOPSD，它从学生自身的去噪轨迹中直接推导出教师的特权，使用同一轨迹中更靠后、更多解码的步骤来评估掩码位置，而不是外部标签，因此教师的优势来自模型自身的解码过程；在Dream和LLaDA上，dOPSD改进了领域内数学推理和领域外代码生成，优于监督和在策略基线。

## Abstract
Diffusion large language models (dLLMs) generate text by iteratively denoising a masked sequence, offering a parallel alternative to autoregressive models, but eliciting strong reasoning through post-training remains difficult: supervised fine-tuning is off-policy and suffers from exposure bias, while reinforcement learning gives only sparse, sequence-level rewards and is hard to apply without tractable sequence likelihoods. On-policy self-distillation (OPSD) offers a promising alternative, using one model as both student and teacher to provide dense, token-level, on-policy supervision, but its effectiveness hinges on giving the teacher privileged information (PI) - typically an instance-specific ground-truth reference unavailable at inference - so the student ends up distilling a weak PI-free consensus policy that yields little improvement on dLLM reasoning. We introduce dOPSD, which instead derives the teacher's privilege directly from the student's own denoising trajectory, evaluating masked positions using later, more-decoded steps of that same trajectory rather than an external label, so the teacher's advantage emerges from the model's own decoding process; on Dream and LLaDA, dOPSD improves both in-domain math reasoning and out-of-domain code generation, outperforming supervised and on-policy baselines.

  - **基于可验证奖励的强化学习（RLVR）**：仅提供稀疏序列级奖励，且扩散模型缺乏可处理的序列似然，难以直接应用。

- **核心问题**：如何为 dLLM 提供一种密集、在策略、且不依赖外部教师或奖励模型的后训练信号，从而有效提升推理能力。
- **整体含义**：本文提出 dOPSD，将教师的特权来源从外部参考解转移到学生自身的去噪轨迹中，利用扩散解码天然存在的“后步窥视前步”优势，实现无需外部标签的在线自蒸馏，显著提升 dLLM 的推理性能。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想

- 利用扩散语言模型解码过程的天然特性：学生在较早的中间去噪步骤预测掩码位置，而教师（同一模型）在较晚的步骤（已解码更多上下文）对同一位置进行预测，后者自然具备更丰富的信息（“窥视前”优势）。这一特权完全来自模型自身的生成轨迹，无需外部参考解。
- 只对正确 rollout（最终答案与真实答案一致）进行蒸馏，避免强化错误。

### 2.2 关键技术细节

1. **学生状态**：从学生自身的去噪轨迹中均匀采样一个中间解码步骤 \(k\)，要求该步骤的掩码比例大于阈值 \(\tau\)（确保仍有足够多的位置可监督）。学生在该步下对掩码位置进行预测。
2. **教师特权**：对于掩码位置 \(i \in M_k\)，收集未来步骤中该位置仍为掩码的所有步骤 \(T_i = \{t : k < t \le K, i \in M_t\}\)。取这些步骤下教师预测分布的平均值 \(\bar{p}_i = \frac{1}{|T_i|}\sum_{t\in T_i} \pi_\theta(\cdot | x, s_t)_i\)。若 \(T_i = \emptyset\)（即下一步就被解码），则退化为使用最终完成 \( \hat{y}\) 下的预测。
3. **蒸馏目标**：使用 token 级广义 Jensen–Shannon 散度（默认前向 KL，β→0）最小化学生分布与教师目标的差异。
4. **验证机制**：对每个 rollout，检查最终答案是否与数据集中的真实答案匹配，仅保留正确 rollout 进行损失计算。
5. **无架构变更**：教师和学生共享同一模型参数，教师目标使用 stop-gradient，梯度只流向学生。

- 输入：数据集 \(S = \{(x_i, a_i)\}\)（问题+最终答案），扩散语言模型 \(\pi_\theta\)，掩码阈值 \(\tau\)。

## 6. 论文的主要结论与发现

- **dOPSD 是唯一在所有基准上均优于基模型的方法**，显著提升推理和代码生成性能。例如 Dream-7B 上 GSM8K 从 81.41 提升到 83.04，MATH500 从 38.97 提升到 42.20；LLaDA-8B 上 MATH500 提升 4.76 点。
- **SFT、GRPO、OPSD 变体均未带来一致提升，甚至损害性能**。OPSD (full-solution) 崩溃最严重，证实 PI 是实例特定的情况下学生只能收敛到弱共识。
- **OPSD 无法直接移植到扩散模型**，原因有二：
  - PI 外部依赖导致 PI 自由崩溃。
  - 随机掩码偏离模型实际解码路径（置信度排序），产生离路径噪声。
- **dOPSD 的特权完全来自轨迹本身**，无需参考解或答案验证（无验证时仍可提升），因此适用于无参考答案的数据集。
- **前向 KL 优于反向 KL**，因其覆盖质量更全面。
- **教师视野越长（完整轨迹）效果越好**。
- **适中的轨迹掩码阈值（τ=0.5）最佳**。
