## 摘要
自演化智能体违背了大多数学习理论保证背后的假设：数据、评估器、组件和假设空间都是由正在更新的策略产生的。我们提出了**SEA**架构，该架构将自我修改限制在一个小的转向适配器和一个围绕*冻结*基础模型的版本化护栏中，并且仅通过一个任意时有效的门来允许每次修改，该门针对固定的错误预算发出可审计的证书。五个循环控制器组合了已发布的保证；由于这类门只能*选择*冻结基础已经产生的行为，因此五个验证器在环机制——最佳N、微步搜索、自生成复制预言、搜索层控制和自我修复——提供了门所需的密集且无需评估器的信号，仅从问题文本计算得出。在包含四个基础模型的52个实例SWE-bench已验证子集上，基础能力是主导且无混杂效应的因素，而在两个强大的基础模型上，一个经过精心设计的无操作复合控制器隔离了该套件的贡献，分别增加了4和5（Glm 5.2从24到28；Gpt从29到34，最佳结果达到65%），事件日志证实其机制被触发并防止了性能退化。这些结果是基于昂贵评估的单次运行；确认运行间方差和调整每任务算法组合是未来的工作。

## Abstract
Self-evolving agents violate the assumption behind most learning-theoretic guarantees: the data, evaluator, components, and hypothesis space are produced by the policy being updated. We present \textbf{SEA}, an architecture that confines self-modification to a small steering adapter and a versioned harness around a \emph{frozen} base model and admits each modification only through an anytime-valid gate that emits an auditable certificate against a fixed error budget. Five loop controllers compose published guarantees; because such gates can only \emph{select} among behaviors the frozen base already produces, five verifier-in-the-loop mechanisms -- best-of-$N$, micro-step search, self-authored reproduction oracles, search-layer control, and self-repair -- supply the dense, grader-free signal the gates require, computed from the issue text alone. On a $52$-instance SWE-bench Verified subset across four base models, base capability is the dominant, confound-free effect, and on two strong base models a deliberate no-op-composite control isolates the suite's contribution at $+4$ and $+5$ (\textsc{Glm}~5.2 $24\to28$; \textsc{Gpt} $29\to34$, the $65\%$ best), with event logs confirming that its mechanisms fire and prevent regressions. Results are single-run on expensive evaluations; confirming run-to-run variance and adapting the per-task algorithm mix are future work.

## 1. 论文的核心问题与整体含义（研究动机和背景）

自演化智能体（self-evolving agents）会利用自己产生的数据、评估器、组件和假设空间来改进自身行为，这违反了大多数学习理论保证（如**持续学习遗忘界**、**偏好优化收敛**、**策略梯度无偏性**、**安全改进**）的**外置环境假设**。作者将这种违反称为**内源循环失败模式**（endogenous-loop failure mode）：更新后的策略生成了它训练的数据、评价它的评估器、构建它的组件以及搜索的假设空间，使得经典的保证不再具有**证书**效力（certified guarantee）。

论文旨在提出一种架构，使自演化过程**可控**、**可审计**，并能在固定的错误预算内发出**任意时可验证的证书**（anytime-valid certificate），同时通过**验证器在环**（verifier-in-the-loop）机制提供密集的、无需人工评估器的信号，使得控制器能够选择冻结基础模型已有的行为。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心架构：四层结构（Four-Layer Architecture）

| 层 | 名称 | 描述 |
|---|---|---|
| L0 | 冻结基础模型 | 预训练LLM，从不更新，仅作为函数调用 |
| L1 | 转向适配器 | 在线可训练的**软策略**，参数为θ ∈ ℝᵏ（k个转向指令的logits），通过softmax采样；只存储分布，不微调权重 |
| L2 | 护栏 | 可变的编排层：系统提示、工具定义、步骤预算、记忆、抽象库、修复管道。由控制器编辑 |
| L3 | 循环控制器 | 五个核心控制器（算法1-5），持有证书、门控、预算、档案；从不参与前向推理 |

### 核心机制：任意时有效门控（Anytime‑Valid Gate）

每个自修改必须通过一个**统计门**，该门使用已发表的**任意时有效推断**工具（如**置信序列**、**e‑process**、**动态遗憾在线学习**、**两时间尺度随机近似**）在**固定错误预算δ₀**内做出决策。门只能**选择**冻结基础模型已经产生过的行为。

### 五个循环控制器（ALG 1–5）

| 控制器 | 问题 | 解决方案 | 作用层 |
|---|---|---|---|
| ALG 1 PPB-CL | 持续学习的遗忘 | PAC‑Bayes后台转移界 + OGD投影 + 依状态信任域 | L1 |
| ALG 2 PNMP-A | 自训练模式崩溃 | 两时间尺度（慢速奖励模型锚定 + 快速策略Nash‑MP） + e‑value漂移门 | 奖励模型q |
| ALG 3 PA-COCOA | 稀疏长时序信用分配 | 反事实贡献估计（COCOA）+ 参数自由硬币投注 + 漂移重启 | L1 |
| ALG 4 SGM-CS | 护栏编辑的自修改 | 配对置信序列 + 依状态校正W₁ + CTHS预算 + 测试趋势放宽 | L2 |
| ALG 5 SDC-QD | 抽象库增长 | Stitch式MDL压缩 + MAP‑Elites质量多样性存档 | L2 |

### 验证器在环机制（ALG 6–10）

为了解决“门只能选择，不能生成”的困境，引入一系列**生成并验证**候选行为的引擎：

- **ALG 6**：最佳N + 基于验证器的局部搜索（已从实时栈中移除）
- **ALG 7**：**微步搜索**（verified micro‑step search）——在单行编辑的粒度上使用波束搜索，配合工作记忆和代价递增的验证级联
- **ALG 8**：**自生成复制预言**（self‑authored reproduction oracles）——模型仅从问题文本编写测试，通过“在未打补丁代码上失败”的准入规则，在循环内提供**无需真实测试**的密集奖励 Vself
- **ALG 9**：搜索层控制器（将ALG 1/3/4/5重定向到搜索层）
- **ALG 10**：**已验证的自修复**（verified self‑repair）——基于实测修复率而不是人工判断来接纳护栏修复原语

## 3. 实验设计

### 基准与数据集

- **SWE-bench Verified**：500个经过人工验证的子集（来自Django、Matplotlib、Flask）
- **工作样本**：固定随机种子抽取的**52个实例**（24个Django，27个Matplotlib，1个Flask）
- **评估**：官方执行式评估——将补丁应用到仓库预修复状态，运行项目真实测试套件，要求所有**失败转通过**（f2p）测试通过且所有**通过转通过**（p2p）测试保持通过

### 对比设置

- **基础模型**（4个）：GEMMA（gemma4:31b-mlx）、QWEN（qwen3.6:27b）、GPT-MINI（gpt-5.4-mini）、GPT（gpt-5.5）。外加一个GLM 5.2。
- **算法开关**：每个模型运行 **无算法栈（单一回合）** 和 **算法栈‑A（8个算法）**，共8个实验单元格（4×2）。
- **控制**：在GPT上运行**无操作复合控制**（策略指令开启，所有算法关闭）以隔离算法贡献（29/52对比baseline 28，证明算法贡献为+5）。GLM 5.2的“off”直接采用无操作控制。
- **GPT单算法消融**：单独运行每个算法（10种配置），对比无操作控制（29/52），确定各自贡献。

- **事件日志**：决策、接受、预言准入、否决、修复触发次数

## 6. 论文的主要结论与发现

1. **基础能力是主导效应**：四个模型的单回合表现排序一致（GEMMA 18 < QWEN 24 < GPT‑MINI 25 < GPT 28），算法栈打开后排序不变（22,25,29,34）。
2. **算法套件带来一致提升**：在所有模型上开/关差异为+1到+6。在GPT和GLM 5.2上，通过无操作控制隔离，算法贡献分别为**+5**（29→34，65%）和**+4**（24→28）。
3. **主要贡献者**：消融显示ALG 2（指令学习器，+5）、ALG 7/8（微步搜索和自生成预言，各+3）、ALG 3（+2）是主要推动力。ALG 6（最佳2）净负面，被移除。
4. **机制行为验证**：事件日志显示全栈导致**run_tests调用增加约50%**，平均回合长度增加约1.3步，说明代理更多进行**闭环调试**。证书控制器中的ALG 2和ALG 3每轮更新，ALG 4/5贡献较少。
5. **不破坏基础**：全栈引入的p2p回归极少（4个 vs 控制3个）。有17/52实例被所有配置解决，10/52从未被任何配置解决（能力/护栏墙）。

## 7. 优点

- **理论规范性**：将任意时有效推断与自演化相结合，使每个自我修改具有**可审计证书**和**已知错误预算**；所有统计原语均基于已发表工作。
- **架构透明度**：四层分离明确，L0冻结保证底层不变，L1/L2可测量，策略变化δ可被信任区域控制。
- **实验设计严谨**：包含无操作控制以消除框架/指令混杂效应；逐步消融定位关键算法；事件日志提供机制级证据而非仅依赖最终指标。
- **实用创新**：自生成复制预言解决了“无真实测试可爬”的困境，微步搜索将可靠性从整体补丁迁移到单行编辑，已验证的自修复避免了人工打补丁的主观性。
- **可扩展性**：算法与API兼容（仅需文本访问），L1梯度只需索引，无需模型内部梯度。

## 8. 不足与局限

- **理论保证不完整**：每个控制器的组合在自演化设置下**仍然是开放猜想**；例如ALG 2的两时间尺度耦合、ALG 4的依状态修正、ALG 3的动态遗憾在内生循环下不再有保障。
- **统计单次运行**：所有结果基于**单次昂贵评估**，无法评估运行间方差，也无法计算显著性。作者承认这是主要局限。
- **自生成预言可能错误**：准入规则仅保证在未打补丁代码上失败，但可能过于严格或产生假阳性；论文明确将补丁称为“有希望”而非“已解决”。
- **慢循环未实现**：将已验证轨迹蒸馏到权重的步骤（slow loop）尚处于设计阶段，未在实验中训练。
- **超参数敏感性**：依状态敏感性ε为行为常数，作为超参数给定，无法在线自适应估计；信任域条件εL<1可能在大规模LLM中失效。
- **保守性**：PAC‑Bayes项可能在高维下变得空泛，DV遗忘界随t增长可能冻结学习；ALG 4保证安全但可能长期无进步。
- **实验覆盖有限**：仅在单一护栏和有限模型上评估；未进行跨护栏/模型的因子研究；52个实例的样本量中等。
- **应用限制**：方法仅在SWE‑bench代码修复任务上验证，未在更广泛的智能体任务（如对话、检索等）上测试。
