## 摘要
训练工具使用代理从自身经验中改进仍然具有挑战性，因为监督微调依赖于固定的教师蒸馏轨迹，而稀疏奖励强化学习为长期交互提供的监督较弱。我们提出了DeepSearch-Evolve，这是一个基于DeepSearch-World构建的网页代理自我蒸馏框架，DeepSearch-World是一个确定且可验证的环境，具有可复现的搜索和页面阅读工具。DeepSearch-World包含从实体级随机游走构建的42万个多跳问答任务，并支持对自我进化有用的关键代理认知行为，包括进度验证、基于事实的反思和故障恢复。DeepSearch-Evolve迭代地执行轨迹生成、过滤、数据混合和微调，以训练更强的代理。在没有蒸馏自更强模型的情况下，DeepSearch-World-9B在开源代理中达到了具有竞争力的性能，在BrowseComp上达到31.2%，在GAIA上达到61.5%，在HotpotQA上达到93.4%，这表明可验证环境能够实现长周期网页代理的可扩展自我进化。我们将发布环境、42万个训练池、验证集、模型和代码，以促进未来关于自我改进深度搜索代理的研究。

## Abstract
Training tool-use agents to improve from their own experience remains challenging, as supervised fine-tuning relies on fixed teacher-distilled trajectories, while sparse-reward reinforcement learning provides weak supervision for long-horizon interactions. We present DeepSearch-Evolve, a self-distillation framework for web agents built on DeepSearch-World, a deterministic and verifiable environment with reproducible search and page-reading tools. DeepSearch-World contains 420K multi-hop QA tasks constructed from entity-level random walks and supports key agentic cognitive behaviors useful for self-evolving, including progress verification, grounded reflection, and failure recovery. DeepSearch-Evolve iteratively performs trajectory generation, filtering, data mixing, and fine-tuning to train stronger agents. Without distillation from more capable models, DeepSearch-World-9B achieves competitive performance compared with open-source agents, reaching 31.2% on BrowseComp, 61.5% on GAIA, and 93.4% on HotpotQA, showing that verifiable environments enable scalable self-evolution for long-horizon web agents. We will release the environment, 420K training pool, validation set, model, and code to facilitate future research on self-improving deep search agents.

### 1. 论文的核心问题与整体含义（研究动机和背景）

-   **核心问题**：如何让大型语言模型（LLM）驱动的、能够使用工具（如搜索引擎）的智能体，不依赖更强教师模型的蒸馏，仅通过自己的交互经验实现有效的自我进化。
-   **背景与挑战**：
    -   **监督微调（SFT）** 依赖固定的教师轨迹，性能容易饱和，学习上限受限于教师模型能力。
    -   **强化学习（RL）** 在长期交互任务中面临稀疏奖励问题，难以判断失败源于哪个具体步骤（如问题表述、工具选择、证据提取等）。

-   **整体含义**：论文认为，解决上述问题的关键在于构建一个**确定且可验证的环境**，它能为智能体的每一步中间行为提供客观、可靠的反馈信号。基于此，可以设计出一种稳定、高效的自我蒸馏流程，使智能体能从自身已验证的成功轨迹中学习并持续进化。

        -   **环境级验证**：环境中存储了每个问题的**目标实体集**。每次工具调用后，环境能自动检查是否获取到了未验证的实体，提供客观的“实体击中”反馈。对于失败的搜索，环境可以提供分阶段的、基于规则的反思信号（从通用信号到更具体的提示），引导智能体重试。

    2.  **教师代理（Scaffold Teacher Agent）**：
        -   **三阶段对话式框架**：包含`Plan`（初始化工作记忆）、`Act`（循环调用工具）、`End`（在证据充分后生成答案）。

### 6. 论文的主要结论与发现

1.  **可验证环境是实现自我进化的关键**：在确定性、可验证的环境中，智能体可以通过自身的交互日志进行可靠的自我改进，摆脱对更强教师模型的依赖。
2.  **DeepSearch-Evolve框架有效**：通过“脚手架轨迹生成 + 轨迹过滤 + 状态内化转换 + 迭代SFT”的流水线，可以显著提升搜索代理的规划、记忆、错误恢复等核心能力。
3.  **性能大幅超越基线**：DeepSearch-World-9B在所有基准测试上均大幅超越其骨干网络Qwen3.5-9B-Instruct，例如在BrowseComp上提升23.8%，在HotpotQA上提升48.1%。
4.  **数据多样性比重复更重要**：进化过程需要足够大且多样的任务池（420K相比100K）才能持续取得进步，避免过拟合和性能饱和。
5.  **状态内化和反思重写是必要的**：将脚手架轨迹中的环境信号重写为智能体自身的推理过程，是成功蒸馏高级认知技能的关键。

### 7. 优点：方法或实验设计上的亮点

-   **概念清晰且实用**：提出的“可验证环境 + 迭代自我蒸馏”路径，比依赖复杂RL或昂贵教师模型的方法更简洁、稳定、可复现。
-   **环境设计的巧妙性**：实体级验证、分阶段反思信号、确定性工具，这些设计精确地解决了长时域代理训练的痛点（稀疏奖励、过程监督缺失）。
-   **“脚手架转ReAct”的蒸馏策略**：这是论文的核心技术亮点。它巧妙地分离了教师（使用脚手架进行高质量探索）和学生（使用标准ReAct进行高效部署）的角色，通过**重写**而非直接模仿来实现技能迁移，避免了定义复杂奖励函数或处理低质量上线策略轨迹的难题。
-   **异步训练框架**：提升系统吞吐量，使大规模迭代训练变得可行。
-   **强有力的实验证明**：在主实验和一系列消融实验中，均提供了扎实的证据证明框架的有效性和关键组件的必要性。

### 8. 不足与局限

-   **环境局限性**：当前环境完全基于维基百科，限制了知识域的多样性和泛化能力。未来需要扩展到更广泛的知识源。
-   **训练策略的优化空间**：论文使用了迭代SFT，但认为RL或更先进的在线策略自我蒸馏（OPSD）可能有更好的上限。如何将规划、错误恢复等高级技能有效地融入RL训练，仍是未解决的问题。
-   **对基线对比的公平性讨论**：虽然论文强调了自身的独特性（不依赖强教师），但这也意味着它与许多同样强大的开源代理并非完全对等的比较。潜在的混杂变量（如不同的工具集、不同的训练规模）可能影响结论的普适性。
-   **潜在偏差**：基于维基百科构建的数据集可能继承其固有的人类偏见。模型的行为和能力（例如在受限的、确定的环境中学会的认知策略）是否能很好地迁移到动态、嘈杂的真实网络环境中，尚存疑虑。论文虽尝试用少量GRPO数据微调来缓解“离线到现实”的差距，但效果验证不够深入。
