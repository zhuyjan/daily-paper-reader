## 摘要
交错使用推理和工具的语言智能体，随着推理链的延长，其性能急剧下降，即使每一步都简单。我们将此归因于上下文稀释：智能体的调查状态（它已确认了什么、怀疑了什么、还需要什么）仅隐式地存在于不断增长的上下文窗口中，早期的发现被后来的检索所埋没。我们引入了SLEUTH，它通过结构化的认知工作记忆使这种状态显式化且可操作：智能体维护了源于来源的已确认事实、按证据排序的活跃假设，以及直接驱动其下一步行动的开放问题。在五个多跳基准和五个既有基线上，SLEUTH的优势随着难度增加而增长，从HotpotQA上的+5分到4跳链上的+11分，在没有多个回合的情况下超越了Reflexion。分析剩余的差距所在，我们识别出证据充分性问题：智能体常常找到答案但未能确定，从而将预算耗尽于不必要的验证。一个轻量级的承诺触发器解决了这个问题，但仅当智能体已经维护了结构化的状态时：对非结构化智能体应用相同的触发器毫无改进，从而将组织化的认知状态隔离为有效承诺的必要条件。最后，在较弱的模型上强制遵循协议，在最难的问题上恢复了高达+19分，这表明智能体组织其推理的方式（而非原始模型能力）是扩展多跳推理的主动因素。

## Abstract
Language agents that interleave reasoning and tool use degrade sharply as reasoning chains lengthen, even when each individual step is easy. We trace this to context dilution: an agent's investigative state (what it has confirmed, what it suspects, and what it still needs) lives only implicitly in a growing context window, where early discoveries are buried under later retrievals. We introduce SLEUTH, which makes this state explicit and actionable through a structured epistemic working memory: the agent maintains Confirmed Facts grounded to sources, Active Hypotheses ranked by evidence, and Open Questions that directly drive its next action. Across five multi-hop benchmarks and five established baselines, SLEUTH's advantage grows with difficulty, from +5 points on HotpotQA to +11 on 4-hop chains, surpassing Reflexion without multiple episodes. Analyzing where the remaining gap lies, we identify the evidence sufficiency problem: agents often find the answer but fail to commit, exhausting their budget on needless verification. A lightweight commitment trigger fixes this, but only when the agent already maintains structured state: the identical trigger applied to an unstructured agent yields no improvement, isolating organized epistemic state as the necessary condition for effective commitment. Finally, enforcing protocol adherence on a weaker model recovers up to +19 points on the hardest problems, showing that how an agent organizes its reasoning, not raw model capability, is the active ingredient for scaling multi-hop reasoning.

- **整体含义**：揭示了当前语言代理在长链推理中的组织瓶颈，即需要一种显式的、结构化的机制来管理“认知状态”，而不仅仅是依赖隐式的上下文窗口。这为设计更 robust 的代理推理框架提供了新方向。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 受人类调查人员（侦探、医生、科学家）维护结构化笔记的启发，提出 **SLEUTH（Structured Layered Evidence-Updated Tracking of Hypotheses）** 框架。
- 通过纯提示工程（prompting only）让代理维护一个 **结构化的认知工作记忆（Epistemic Working Memory）**，在每一步明确输出三类组件，使调查状态显式化、可操作。

### 关键技术细节
- **工作记忆结构**（每轮更新 `W_t = (F_t, H_t, Q_t)`）：
  - **已确认事实（Confirmed Facts）** `F_t`：从工具输出中提取的可验证陈述，每条附带来源标题，单调累积，不撤回。
  - **活跃假设（Active Hypotheses）** `H_t`：候选答案，按证据支持度排名，每条关联支持/矛盾的事实ID，具有置信度（高/中/低）。
  - **开放问题（Open Questions）** `Q_t`：未解决的不确定性，每条附带建议动作（如搜索查询）和优先级。最高优先级的开放问题直接决定下一轮工具调用。
- **更新协议**（每轮工具调用后）：
  1. 从输出中提取新事实，添加至 `F_t`。
  2. 更新假设的置信度，生成新假设。
  3. 移除已解决的开放问题，生成新的开放问题（针对能最大改变假设排名的未知项）。
  4. 选择最高优先级的开放问题的动作执行；若 `Q_t` 为空且存在高置信度假设，则调用 `finish(answer)`。
- **承诺机制（Nudge 机制）**：
  - 解决 **证据充分性问题（Evidence Sufficiency Problem）**：代理找到答案但因标准过高而不确定，耗尽预算。
  - 触发条件：轮次 `t ≥ αT`（α=0.7）且 `|F_t| ≥ 2`。
  - 触发后，代理收到合成消息，被迫基于已有事实和假设生成答案，停止进一步探索。
  - 该机制仅在代理已维护结构化状态时有效；对非结构化代理（如 ReAct）施加相同触发无效果。
- **实现细节**：完全通过提示实现，无需微调或架构修改。工具接口包括 `search(query)`、`lookup(title)`、`finish(answer)`。对弱模型（GLM-5）使用提示适配和运行时格式检查以确保协议遵守率接近99%。

## 6. 主要结论与发现

1. **SLEUTH 显著优于所有基线**，优势随难度增加：HotpotQA +4.7pp，MuSiQue 4-hop +10.9pp，2Wiki +2.8pp（Claude Sonnet）。

6. **剩余错误**：主要来自推理质量（从正确证据推论错误），而非检索或状态管理。
