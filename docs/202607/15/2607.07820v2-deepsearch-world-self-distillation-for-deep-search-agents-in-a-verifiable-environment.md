## 摘要
训练工具使用智能体从自身经验中改进仍具挑战性，因为监督微调依赖于固定的教师蒸馏轨迹，而稀疏奖励强化学习为长程交互提供的监督较弱。我们提出了DeepSearch-Evolve，这是一个基于DeepSearch-World构建的网络智能体自蒸馏框架。DeepSearch-World是一个确定性和可验证的环境，具有可复现的搜索和页面阅读工具。DeepSearch-World包含42万个基于实体级随机游走构建的多跳问答任务，并支持对自进化至关重要的关键智能体认知行为，包括进度验证、基于实际的反思和失败恢复。DeepSearch-Evolve迭代进行轨迹生成、过滤、数据混合和微调，以训练更强的智能体。在没有从更强大模型进行蒸馏的情况下，DeepSearch-World-9B在开源智能体中取得了有竞争力的性能，在BrowseComp上达到31.2%，在GAIA上达到61.5%，在HotpotQA上达到93.4%，表明可验证环境能够实现长程网络智能体的可扩展自进化。我们将发布环境、42万训练池、验证集、模型和代码，以促进未来对自改进深度搜索智能体的研究。

## Abstract
Training tool-use agents to improve from their own experience remains challenging, as supervised fine-tuning relies on fixed teacher-distilled trajectories, while sparse-reward reinforcement learning provides weak supervision for long-horizon interactions. We present DeepSearch-Evolve, a self-distillation framework for web agents built on DeepSearch-World, a deterministic and verifiable environment with reproducible search and page-reading tools. DeepSearch-World contains 420K multi-hop QA tasks constructed from entity-level random walks and supports key agentic cognitive behaviors useful for self-evolving, including progress verification, grounded reflection, and failure recovery. DeepSearch-Evolve iteratively performs trajectory generation, filtering, data mixing, and fine-tuning to train stronger agents. Without distillation from more capable models, DeepSearch-World-9B achieves competitive performance compared with open-source agents, reaching 31.2% on BrowseComp, 61.5% on GAIA, and 93.4% on HotpotQA, showing that verifiable environments enable scalable self-evolution for long-horizon web agents. We will release the environment, 420K training pool, validation set, model, and code to facilitate future research on self-improving deep search agents.

- **核心问题**：如何让执行多步操作的网络搜索智能体（Web Agents）能够**自主地、持续地从自身的交互经验中学习和改进**。
- **现有方法困境**：
    - **监督微调（SFT）**：依赖固定的、来自教师的经验，很快遇到性能瓶颈。
    - **强化学习（RL）**：奖励信号稀疏，通常只在最终结果给出，难以指导长程交互过程中的特定步骤（如查询调整、工具选择、证据提取）进行优化。
- **本文贡献**：提出一个包含**可验证环境**和**自蒸馏框架**的完整方案，旨在为长程智能体提供密集、可靠的中间监督信号，实现可扩展的自我进化，而无需依赖更强模型的蒸馏。

### 2. 论文提出的方法论

核心思想是构建一个**确定性、可验证的离线环境**，并在此环境中设计一套**迭代自蒸馏**的训练流程。

- **核心技术：DeepSearch-World（可验证环境）**
    - **确定性工具**：基于离线Wikipedia语料库，提供`web_search_wiki`（BM25检索）和`visit_wiki`（SQLite索引读取全文）两个工具。所有观测结果可复现、可验证。
    - **基于实体的进度验证**：环境内置每道题的隐藏目标实体集合（`Ti`）。智能体每完成一次成功的工具调用（匹配一个未解决实体），环境状态即更新，实现了**过程级监督**，无需昂贵的大模型判断。
    - **脚手架（Scaffold）教师智能体**：采用“规划-行动-结束”三阶段协议，增加了明确的`completed_list`、`todo_list`、`experience`（失败经验）和`information`字段，用于引导智能体进行规划、记忆和错误恢复。

- **核心技术：DeepSearch-Evolve（自蒸馏框架）**
    - **迭代流程**：一个循环，包含**轨迹生成**、**过滤**、**数据混合**和**微调**。
        1. **教师生成**：当前模型在可验证环境中作为教师，使用Scaffold协议生成轨迹。
        2. **过滤**：通过“拒绝采样”（仅保留最终答案正确的轨迹）和“质量过滤”（LLM筛选掉冗余、不一致的轨迹）筛选高质量轨迹。
        3. **Scaffold-to-ReAct转换**：将教师轨迹中专门的scaffold格式（如`[STATE_UPDATE]`）转换为标准的`<think>`推理和`<tool_call>`动作的ReAct格式，训练出可直接部署的智能体。
        4. **监督自蒸馏更新**：使用过滤并转换后的ReAct轨迹对学生模型进行SFT（本质上是`KL(δ_y || π_θ)`的硬标签蒸馏）。这种“部分在策略”的训练方式，比完全在策略的分布匹配（如OPSD）更稳定，因为它避免了在低质量状态下的噪声监督。

### 6. 论文的主要结论与发现

- **核心发现**：一个**确定性的、可提供过程级监督的环境**，结合**迭代的自蒸馏训练框架**，足以让开源模型在长程工具使用任务中实现**显著的、自主的自我进化**。
- **关键条件**：
    - **多样化的训练数据池**是自进化的关键。大的数据池（42万 vs 10万）能提供更多样化的学习信号，避免对窄模式过拟合。
    - **成功的行为（失败与反思）**对学习至关重要。Scaffold教师生成的轨迹，特别是其中的失败恢复和反思过程，被成功蒸馏到学生模型的行为中。
- **性能对比**：无需依赖强模型（如GPT-4、Claude等）产生的合成数据，仅用自身经验就能达到与先进开源代理相抗衡的水准。
