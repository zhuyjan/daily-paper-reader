## 摘要
强化学习（RL）搜索智能体通常将检索建模为自由形式的自然语言查询生成，并使用最终答案奖励来优化多轮交互。当前研究主要通过更密集或更结构化的信用信号来改进训练，但很少检验检索在策略-环境接口处是否被恰当构建。我们在Search-R1训练过程中观察到明显的检索混叠现象：同一问题的rollout持续生成不同的查询字符串，但它们累积的证据集却日益重叠。我们将此现象称为检索等价坍缩；在该状态下，轨迹在检索决策方面趋于效用等价，导致组内回报缺乏有效的检索对比。为解决此问题，我们提出Harness-G，一种图结构检索框架，重新设计了该接口。它将自由形式的查询生成重构为有限动作选择：策略选择一个证据句子或实体，或选择回答，而环境负责构建菜单、跟踪检索状态，并验证和执行每个选择。该接口减少了语言混叠，使得同一状态下的备选动作可直接比较。在此基础上，我们引入结构化非近视信用（SNC），利用冻结的答案评分器将所选动作与其备选动作进行比较，并将下游收益分配给使这些收益成为可能的早期动作。在六个问答基准上，Harness-G在两种评估模型规模下均取得最高平均F1分数，在1.5B规模下比最强基线Graph-R1高出10.74分，在3B规模下高出3.98分。

## Abstract
Reinforcement learning (RL) search agents commonly model retrieval as free-form natural-language query generation and optimize multi-turn interactions using final-answer rewards. Current studies mainly improve training with denser or more structured credit signals, but rarely examine whether retrieval is properly formulated at the policy-environment interface. We observe pronounced retrieval aliasing during Search-R1 training: rollouts for the same question continue to generate distinct query strings, yet their accumulated evidence sets increasingly overlap. We call this phenomenon retrieval-equivalence collapse; in this regime, trajectories approach utility equivalence with respect to retrieval decisions, leaving within-group returns with little effective retrieval contrast. To address this problem, we propose Harness-G, a graph-structured retrieval framework that redesigns this interface. It reformulates free-form query generation as finite action selection: the policy selects an evidence sentence or entity, or chooses to answer, while the environment constructs the menu, tracks retrieval state, and validates and executes each choice. This interface reduces linguistic aliasing and makes same-state alternatives directly comparable. Building on this interface, we introduce Structured Non-myopic Credit (SNC), which uses a frozen answer scorer to compare the selected action with its alternatives and assigns downstream gains to the earlier actions that enabled them. Across six QA benchmarks, Harness-G achieves the highest average F1 at both evaluated model scales, outperforming the strongest baseline, Graph-R1, by 10.74 points at 1.5B and 3.98 points at 3B.

## 1. 核心问题与整体含义

- **动机**：强化学习（RL）搜索智能体（如 Search-R1）通常将检索建模为**自由形式的自然语言查询生成**，并用最终答案奖励优化完整的多轮交互轨迹。已有工作主要通过引入过程奖励、信息增益等更密集信号来改进训练，但很少质疑“自由文本查询 → 证据检索”这一**策略-环境接口**本身是否适合 RL 优化。
- **关键观察**：作者在 Search-R1 训练中发现了**检索等价坍缩（retrieval-equivalence collapse）**——同一问题产生的 rollout 虽然持续生成表面不同的查询字符串，但累积证据集的交集越来越大。也就是说，查询形式的多样性并未转化为检索结果的有效多样性。
- **直接后果**：
  - 同一 rollout 组内的轨迹在检索决策上趋于“效用等价”，GRPO 的组内优势（advantage）逐渐消失，名义上的多样化采样实际只剩很少的有效检索样本。
  - 检索信用被混淆：若相同证据产生不同答案，回报差异更多反映推理或答案生成质量，而不是检索质量。仅靠过程奖励无法从根本上恢复检索层面的对比度，因为它仍保留“自由查询 → 检索结果”的多对一映射。
- **整体含义**：论文主张，搜索智能体优化的关键不仅在于“如何评估轨迹”（奖励设计），还在于**“检索动作如何被表征和暴露给策略”**（动作空间/接口设计）。Harness-G 通过将自由查询重新定义为图结构上的有限动作选择，从结构上消除语言混叠，并基于可枚举动作前沿设计新的信用分配机制，开辟了“动作空间设计 + 信用分配”互补的优化思路。

## 2. 方法论

### 2.1 核心思想

Harness-G 将多跳检索从“生成查询字符串”重构为“在状态化图环境中进行有限动作导航”：

- 策略不再输出自然语言查询，而是从环境生成的**有限动作菜单**中选择一个动作 ID。
- 环境负责构造查询、执行检索、更新状态并验证动作合法性。
- 动作包括：`Select`（将可见句子提交为证据）、`Lookup`（围绕某个实体检索）、`Answer`（终止并生成答案），以及可选的 `Answer_With`（提交可见句子并一步终止）。
- 由此带来三个关键性质：**有限性**（动作数量有上限）、**可验证性**（动作类型与目标显式合法）、**可预览性**（用读操作展开任一候选动作的结果，不改变真实状态），后者为信用分配提供基础。

### 2.2 离线图构建：段落–句子–实体三分图

- 从原始语料以程序化方式构建图，**不调用生成式 LLM**：
  - 句子切分、NER（SpaCy）、稠密编码；
  - 节点：段落、句子、实体；
  - 边：段落–句子、句子–实体、句子–句子（相邻句）、实体–实体（表面归一化、标题锚定、缩写匹配、可选嵌入邻居），实体–实体边仅用于候选召回。
- 复杂度近线性，一次构建、跨运行复用。

### 2.3 在线菜单环境

- 每集开始执行 `InitRetrieve(q; G)` 融合多通道召回；之后每步策略必须从菜单选择动作 ID。
- 环境确定性执行：
  - `Select(s)`：提交可见句子到证据集 C_t；
  - `Lookup(e)`：环境用 `concat(q, text(C_t))` 检索候选句子，扩展候选集；
  - `Answer`：基于已提交证据生成答案。
- 菜单生成时过滤：已提交句子、重复检索、已访问实体、低价值目标（日期、基数、国籍形容词等）均不出现。

### 2.4 SNC：结构化非近视信用（Structured Non-myopic Credit）

SNC 只依赖环境内部计算，无外部奖励模型、无额外 rollout，包含两项互补信用：

1. **前沿相对优势（frontier-relative advantage）**：
   - 冻结答案评分器 g(O)=P_{θ̄}(y* | q, O)，衡量证据对标准答案的支持度；
   - 每个信息获取动作的边际增益：p_t(a)=g(O_t ∪ Ũ(a))−g(O_t)；
   - 选择一个有界反事实前沿 F_t（类型分层、去重、上限 K_f），计算备选平均增益 p̄_t；
   - 前沿相对优势：r^fr_t = p_t(a_t) − p̄_t。
   - 只有优于同状态可行备选才获得正信用，而非“检索到东西就给奖赏”。

2. **使能信用（enablement credit）**：
   - 记录 provenance 边 (t,u)（u 步骤消费了 t 步骤产生的句子/实体），按逆拓扑序传播：
     R_u = p_u(a_u) + γ r^en_u，r^en_t = Σ_{u:(t,u)∈Dτ} R_u / |Pred(u)|；
   - 让早期“桥接实体”动作获得后续下游收益，缓解逐步步进边际低估早期关键动作的问题。

3. **与 GRPO 集成**：
   - 轨迹回报仍为 token 级答案 F1，GRPO 归一化得到 Â_out；
   - SNC 信用按动作 token 跨度均匀放置，归一化裁剪后得到 Â_SNC；
   - 总 token 级优势：Â_i,k = Â_out_i + λ Â_SNC_i,k；
   - 环境注入的检索 tokens 被 loss-mask，不参与更新。

### 2.5 训练流程

先离线建图；每轮迭代对 batch 内每个问题采样多个 rollout；执行环境菜单交互；计算 SNC 信用（预览+评分+传播）；用带双裁剪和 KL 正则的 clipped surrogate 更新策略。

## 6. 主要结论与发现

- **主结果**：Harness-G 在两种规模下平均 F1 均最高——3B 达 55.24，超过 Graph-R1（51.26）3.98 分；1.5B 达 50.83，超过 Graph-R1（40.09）10.74 分。
- **多跳任务收益显著**：3B 下在 2Wiki/HotpotQA/MuSiQue 上分别提升 7.97/9.12/5.95 F1，平均 +7.68；单跳 NQ 上略低于 Graph-R1（-1.84 F1）。
- **小模型获益更大**：1.5B 提升幅度远超 3B，说明结构化有限动作接口对容量受限模型更有价值。
- **菜单接口是关键**：仅将自由查询换成动作菜单，在相同图和奖励下就带来超过 17 点的 F1 提升；MuSiQue 上在 outcome-only 训练下提升超过 35 点。
- **SNC 有效**：完整 SNC 在所有多跳数据集上最优；去掉任何一项（frontier/enable）都会下降；去掉全部（λ=0）在 2Wiki/HotpotQA/MuSiQue 上分别下降 3.08/4.55/2.88 F1。
- **训练稳定**：训练过程无持续崩溃，梯度范数有界；可迁移到不同 backbone 与 RL 算法。
- **交互更高效**：虽然轮次增加，但响应侧 token 数反而下降，说明结构化导航能更聚焦。
- **泛化能力更强**：跨数据集 OOD 平均 F1 从 Graph-R1 的 44.10 提升到 47.38（+3.29），在 30 个 off-diagonal 对中赢得 21 个；零样本垂直领域迁移也领先。

## 7. 优点

- **问题诊断清晰**：提出“检索等价坍缩/虚幻探索”概念，并给出了可量化的多样性指标（查询形式多样性 vs 检索结果多样性），直击 RL 搜索训练中的结构性失效。
- **接口设计创新**：将检索从“字符串生成”重构为“环境可枚举、可验证、可预览的有限动作选择”，使同状态备选可以被直接比较，从根本上缓解语言混叠。
