## 摘要
智能体自我进化主要聚焦于学习如何行动，却忽视了同等重要的能力：发现智能体自身不知道的事情。现有方法通常假设失败发现是给定的，专注于一旦识别出失败如何修复。我们探究盲点诊断本身是否可以被学习。因此，我们将诊断视为与执行分离的智能体能力，并排除了两种替代进步来源：执行器适应和人工监督。在这些约束下，性能无法通过执行器更新或人工标注示例来提升，迫使所有改进都源自于习得的诊断能力。我们提出了 SkillMentor，它通过强化学习训练一个 Mentor 策略，用于生成诊断任务、识别反复出现的失败模式，并将其整理成可复用的纠正技能。在 AppWorld 和 BFCLv3 上，SkillMentor 将执行器性能平均提升了 44.2%。这些结果表明，盲点诊断是一种可学习的能力，能够在不更新执行器权重或依赖人工整理数据的情况下实现自我进化。

## Abstract
Agent self-evolution has primarily focused on learning how to act, while overlooking an equally important capability: learning to discover what an agent does not know. Existing approaches typically assume that failure discovery is given, focusing on how to repair failures once they are identified. We ask whether blind-spot diagnosis itself can be learned. We thus study diagnosis as an agent capability separate from execution, and exclude two alternative sources of progress: executor adaptation and human supervision. Under these constraints, performance cannot improve through executor updates or annotated examples, forcing all improvements to originate from the learned diagnostic capability. We propose SkillMentor, which trains a Mentor policy via reinforcement learning to generate diagnostic tasks, identify recurrent failure modes, and curate them into reusable corrective skills. Across AppWorld and BFCLv3, SkillMentor improves executor performance by an average of 44.2%. These results suggest that blind-spot diagnosis is a learnable capability, enabling self-evolution without updating executor weights or relying on human-curated data.

## 2. 方法论

- **整体思想**：训练一个独立于执行器的 **Mentor策略 πθ**，通过强化学习（GRPO）主动发现执行器的盲点，并将其转化为可复用的外部技能仓库。诊断与执行分离，适应通过外部技能库实现，而非修改执行器权重。
- **问题形式化**：
  - 盲点定义为元组 b = (T, c)，其中 T 是执行器持续欠佳的任务，c 是能缓解失败的纠正技能。
  - 在每个时间步，Mentor决定动作 a_t = (q_t, c_t)，其中 q_t 为诊断任务，c_t 为技能整理决策。
  - 优化目标为最大化累计奖励：E[∑(r_disc(q_t) + r_curate(c_t))]。
- **三阶段流程**：
  1. **盲点发现（Blind-Spot Discovery）**：Mentor在环境中自由探索（无预定义目标），通过与API/工具交互生成轨迹，并从轨迹中合成 G 个候选诊断任务；再利用多样性缓冲区（diversity buffer）防止探索坍缩。
  2. **间隙评估（Gap Evaluation）**：对每个候选任务 q_i，用强参考模型 M 生成参考轨迹并打分 s_i^M，用冻结执行器 π_E 在现有技能库辅助下生成轨迹并打分 s_i^E。诊断间隙 δ_i = max(0, s_i^M − s_i^E)，作为发现奖励 r_disc。选择间隙最大的任务进入技能整理。
  3. **技能整理（Skill Curation）**：Mentor基于失败轨迹和现有技能生成 G 个候选技能，支持 **ADD / UPDATE / MERGE** 三种操作。候选技能需通过两个验证：①语法有效性（符合预定义格式）；②执行器接地效用（执行器重试后提升 Δ > 0.5 才允许入库）。整理奖励 r_curate = 0.3·f(c) + 0.7·Δ，其中 f(c) 为格式合规指示。另有 **DELETE** 机制，技能成功率低于0.05时被淘汰。
- **联合优化**：使用GRPO同时优化发现奖励和整理奖励，共享策略参数。当间隙低于自适应阈值（线性衰减，0.5→0.2）时跳过技能整理，只更新发现信号。
- **推理阶段**：执行器从技能库中按任务描述检索相关技能，拼接到提示词中。技能库既是诊断的产物，也是自我进化的引擎，促使执行器能力边界逐步迁移。

## 6. 主要结论与发现

- **学习能够提升诊断能力**：RL训练的4B Mentor一致优于更强的提示式Mentor（DeepSeek-V4-Flash），说明诊断不是模型规模的副产品，而是可优化的能力。
- **联合优化是必要的**：发现与整理奖励共享策略参数时性能最好；去除任一奖励或者分离参数都会显著下降，证明发现与整理存在正反馈循环。
- **弱执行器收益更大**：相对提升最大的是DeepSeek-R1-Distill-Qwen-7B（+46.6%），最小的是Qwen3.5-9B（+36.7%），符合盲点作为程序性缺陷的设定。
- **技能具有可迁移性**：弱执行器学到的技能向强执行器传输尤其有效；所有跨执行器部署均超过No Skill基线。
- **盲点是非平稳的**：随着技能积累，平均诊断间隙下降，新盲点不断暴露；线性衰减的阈值比静态/上升阈值更稳定。
- **强模型依赖轻且稳健**：SkillMentor只使用强模型作为训练时的LLM judge，推理时不依赖；低成本的Flash级judge即可取得接近旗舰级的效果。

## 7. 优点

- **问题设定清晰**：将诊断从执行中分离出来，通过冻结执行器和零标注数据隔离了诊断能力，避免了混淆来源。
- **方法设计巧妙**：发现-整理联合优化形成自我增强的反馈环，将外部技能库作为“诊断产品”，使改进可观测、可编辑、可迁移。
- **可解释性强**：技能以人类可读的Markdown存储，可直接分析执行器的盲点分布，案例研究展示了具体修复机制。
